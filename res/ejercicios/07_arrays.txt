    int mejor = 0;

        } else {
            actual = 0;
        }

enunciado.en: danio[r] is the array of hits in round r, and each round can have a different number of hits. Return an array with the total damage of each round. Example: sumaPorFila(new int[][]{{1, 2}, {3, 4, 5}}) returns {3, 12}.
pista.es: Un int[][] es un array de arrays: danio.length es el número de rondas y danio[r].length los golpes de la ronda r. Usa dos bucles anidados.

        }

=== t07_mezclar_rankings
tema: 07
dificultad: 5
java: 8
tipo: metodo
titulo.es: Juntar dos clasificaciones ordenadas
titulo.de: Zwei sortierte Ranglisten zusammenführen
titulo.en: Merge two sorted rankings
enunciado.es: a y b son dos clasificaciones de puntos, cada una ordenada de menor a mayor. Devuelve un array con todos los puntos de las dos, también ordenado, sin ordenar al final: recórrelas a la vez. Ejemplo: mezclar(new int[]{1, 4, 9}, new int[]{2, 3, 10}) devuelve {1, 2, 3, 4, 9, 10}.
enunciado.de: a und b sind zwei Punkteranglisten, jede aufsteigend sortiert. Gib ein Array mit allen Punkten aus beiden zurück, ebenfalls sortiert, ohne am Ende zu sortieren: Geh beide gleichzeitig durch. Beispiel: mezclar(new int[]{1, 4, 9}, new int[]{2, 3, 10}) gibt {1, 2, 3, 4, 9, 10} zurück.
enunciado.en: a and b are two point rankings, each sorted from lowest to highest. Return an array with all the points from both, also sorted, without sorting at the end: walk through both at the same time. Example: mezclar(new int[]{1, 4, 9}, new int[]{2, 3, 10}) returns {1, 2, 3, 4, 9, 10}.
pista.es: Un índice para a, otro para b y otro para el resultado. Copia siempre el menor de a[i] y b[j]; cuando uno se acabe, copia lo que quede del otro.
pista.de: Ein Index für a, einer für b und einer für das Ergebnis. Kopier immer den kleineren von a[i] und b[j]; ist eines zu Ende, kopier den Rest des anderen.
pista.en: One index for a, one for b and one for the result. Always copy the smaller of a[i] and b[j]; when one runs out, copy whatever is left of the other.
firma: static int[] mezclar(int[] a, int[] b)
plantilla:
    return a;
solucion:
    int[] juntos = new int[a.length + b.length];
    int i = 0;
    int j = 0;
    int k = 0;
    while (i < a.length && j < b.length) {
        if (a[i] <= b[j]) {
            juntos[k++] = a[i++];
        } else {
            juntos[k++] = b[j++];
        }
    }
    while (i < a.length) {
        juntos[k++] = a[i++];
    }
    while (j < b.length) {
        juntos[k++] = b[j++];
    }
