enunciado.en: Your robot is at (x, y) and the enemy at (ex, ey), moving in a straight line on heading rumboEnemigo (degrees) at velocidadEnemigo per turn. pista.es: Tras t turnos el enemigo está en (ex + vx·t, ey + vy·t) y la bala ha recorrido velocidadBala·t. pista.de: Nach t Runden ist der Gegner bei (ex + vx·t, ey + vy·t), und die Kugel hat velocidadBala·t zurückgelegt. Setzt man die Abstände gleich, ergibt sich eine quadratische Gleichung in t: (v² - velocidadBala²)·t² + 2(D·V)·t + D·D = 0, mit D = (ex - x, ey - y). pista.en: After t turns the enemy is at (ex + vx·t, ey + vy·t) and the bullet has travelled velocidadBala·t. Setting the distances equal gives a quadratic in t: (v² - velocidadBala²)·t² + 2(D·V)·t + D·D = 0, with D = (ex - x, ey - y). Take the smallest positive t (and watch out when the first coefficient is 0).
firma: static double anguloDeIntercepcion(double x, double y, double ex, double ey, double rumboEnemigo, double velocidadEnemigo, double velocidadBala)
plantilla:
    return Math.toDegrees(Math.atan2(ey - y, ex - x));
solucion:
    double dx = ex - x;
    double dy = ey - y;
    double rumbo = Math.toRadians(rumboEnemigo);
    double vx = velocidadEnemigo * Math.cos(rumbo);
    double vy = velocidadEnemigo * Math.sin(rumbo);
    double a = vx * vx + vy * vy - velocidadBala * velocidadBala;
    double b = 2 * (dx * vx + dy * vy);
    double c = dx * dx + dy * dy;
    double t = 0;
    if (Math.abs(a) < 1e-9) {
        if (b < 0) {
            t = -c / b;
        }
    } else {
        double discriminante = b * b - 4 * a * c;
        if (discriminante >= 0) {
            double raiz = Math.sqrt(discriminante);
            double t1 = (-b - raiz) / (2 * a);
            double t2 = (-b + raiz) / (2 * a);
            double menor = Math.min(t1, t2);
            double mayor = Math.max(t1, t2);
            t = menor > 0 ? menor : Math.max(mayor, 0);
        }
    }
    return Math.toDegrees(Math.atan2(dy + vy * t, dx + vx * t));

pista.de: Um einen Winkel auf (-180, 180] zu bringen: r = a % 360; ist r > 180, r -= 360; ist r <= -180, r += 360. Nutz das für jedes d und fürs Ergebnis. Das Begrenzen: Math.max(-45, Math.min(45, d)).
pista.en: To bring an angle into (-180, 180]: r = a % 360; if r > 180, r -= 360; if r <= -180, r += 360. Use it for each d and for the result. The clipping: Math.max(-45, Math.min(45, d)).
firma: static double siguienteBarrido(double apuntado, List<Double> vistos)
plantilla:
    return apuntado + 45;
solucion:
    DoubleUnaryOperator normalizar = a -> {
        double r = a % 360;
        if (r > 180) {
            r -= 360;
        } else if (r <= -180) {
            r += 360;
        }
        return r;
    };
    double giro = 45;
    if (!vistos.isEmpty()) {
        Double mejor = null;
        for (double visto : vistos) {
            double d = normalizar.applyAsDouble(visto - apuntado);
            if (mejor == null || Math.abs(d) < Math.abs(mejor) || (Math.abs(d) == Math.abs(mejor) && d > mejor)) {
                mejor = d;
            }
        }
        giro = Math.max(-45, Math.min(45, mejor));
    }
    return normalizar.applyAsDouble(apuntado + giro);

solucion:
    public class Esquiva {
        private static final double ANCHO = 1000;
        private static final double ALTO = 700;

        public static double rumbo(double x, double y, double rumboDisparo) {
            double izquierda = normalizar(rumboDisparo + 90);
            double derecha = normalizar(rumboDisparo - 90);
            return sitio(x, y, izquierda) >= sitio(x, y, derecha) ? izquierda : derecha;
        }

        /** Cuánto se puede avanzar en línea recta con ese rumbo antes de chocar con una pared. */
        private static double sitio(double x, double y, double rumbo) {
            double dx = Math.cos(Math.toRadians(rumbo));
            double dy = Math.sin(Math.toRadians(rumbo));
            return Math.min(hastaLaPared(x, dx, ANCHO), hastaLaPared(y, dy, ALTO));
        }

        private static double hastaLaPared(double posicion, double paso, double limite) {
            if (Math.abs(paso) < 1e-9) {
                return Double.POSITIVE_INFINITY;
            }
            return paso > 0 ? (limite - posicion) / paso : -posicion / paso;
        }

        private static double normalizar(double grados) {
            double r = grados % 360;
            if (r > 180) {
                return r - 360;
            }
            return r <= -180 ? r + 360 : r;
        }
    }
