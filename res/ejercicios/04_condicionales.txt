=== t04_danio_final
tema: 04
dificultad: 5
java: 8
tipo: metodo
titulo.es: El cálculo completo del daño
titulo.de: Die komplette Schadensberechnung
titulo.en: The full damage calculation
enunciado.es: Calcula el daño de un golpe con estas reglas, en orden: con el escudo puesto, o si danio es 0 o menos, el daño es 0. Si es crítico, danio se duplica. Luego se resta la armadura, pero un golpe que llega siempre hace al menos 1. Ejemplo: danioFinal(10, 3, true, false) devuelve 17.
enunciado.de: Berechne den Schaden eines Treffers nach diesen Regeln, der Reihe nach: Ist der Schild aktiv oder danio 0 oder weniger, ist der Schaden 0. Bei einem kritischen Treffer verdoppelt sich danio. Dann wird die Panzerung abgezogen, aber ein Treffer, der durchkommt, macht immer mindestens 1. Beispiel: danioFinal(10, 3, true, false) gibt 17 zurück.
enunciado.en: Work out a hit's damage with these rules, in order: with the shield up, or if danio is 0 or less, the damage is 0. On a critical hit, danio doubles. Then the armor is subtracted, but a hit that gets through always does at least 1. Example: danioFinal(10, 3, true, false) returns 17.
pista.es: Sal pronto con return 0 en el primer caso. Después, una variable total: dóblala si critico, réstale la armadura y devuelve Math.max(total, 1).
pista.de: Steig im ersten Fall mit return 0 früh aus. Danach eine Variable total: verdoppeln, wenn critico, die Panzerung abziehen und Math.max(total, 1) zurückgeben.
pista.en: Leave early with return 0 in the first case. After that, a variable total: double it if critico, subtract the armor and return Math.max(total, 1).
firma: static int danioFinal(int danio, int armadura, boolean critico, boolean escudo)
plantilla:
    return danio - armadura;
solucion:
    if (escudo || danio <= 0) {
        return 0;
    }
    int total = danio;
    if (critico) {
        total *= 2;
    }
    total -= armadura;
    return Math.max(total, 1);
casos:
    danioFinal(10, 3, false, false) => 7
    danioFinal(10, 3, true, false) => 17
    danioFinal(10, 3, true, true) => 0
    danioFinal(2, 5, false, false) => 1
    danioFinal(4, 4, false, false) => 1
    danioFinal(0, 5, true, false) => 0
    danioFinal(-3, 0, false, false) => 0
