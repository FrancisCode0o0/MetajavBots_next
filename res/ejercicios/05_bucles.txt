=== t05_cuenta_atras
tema: 05
dificultad: 1
java: 8
tipo: salida
titulo.es: Cuenta atrás para el combate
titulo.de: Countdown zum Kampf
titulo.en: Countdown to the fight
enunciado.es: Imprime los números de n a 1, cada uno en su línea, y al final GO!. Ejemplo: cuentaAtras(3) imprime 3, 2, 1 y GO!. Con n = 0, solo GO!.
enunciado.de: Gib die Zahlen von n bis 1 aus, jede in einer eigenen Zeile, und zum Schluss GO!. Beispiel: cuentaAtras(3) gibt 3, 2, 1 und GO! aus. Bei n = 0 nur GO!.
enunciado.en: Print the numbers from n down to 1, each on its own line, and then GO!. Example: cuentaAtras(3) prints 3, 2, 1 and GO!. With n = 0, just GO!.
pista.es: Un for que baja: for (int i = n; i >= 1; i--) { ... }. El GO! va después del bucle, no dentro.
pista.de: Eine for-Schleife, die abwärts zählt: for (int i = n; i >= 1; i--) { ... }. Das GO! kommt nach der Schleife, nicht hinein.
pista.en: A for loop that counts down: for (int i = n; i >= 1; i--) { ... }. The GO! goes after the loop, not inside it.
firma: static void cuentaAtras(int n)
plantilla:
    System.out.println("GO!");
solucion:
    for (int i = n; i >= 1; i--) {
        System.out.println(i);
    }
    System.out.println("GO!");
casos:
    cuentaAtras(3); => "3\n2\n1\nGO!\n"
    cuentaAtras(1); => "1\nGO!\n"
    cuentaAtras(5); => "5\n4\n3\n2\n1\nGO!\n"
    cuentaAtras(0); => "GO!\n"

pista.de: Fang mit int suma = 0; an und nimm eine for-Schleife von 1 bis n mit suma += i;

solucion:

    for (int i = 1; i <= n; i++) {

titulo.es: ¿De cuántas formas se montan?
titulo.de: Auf wie viele Arten lässt es sich bauen?
titulo.en: How many ways to assemble it?
enunciado.es: n piezas distintas se pueden montar en n! órdenes: n! = 1 · 2 · … · n, y 0! vale 1. Devuelve n! como long. Ejemplo: factorial(5) devuelve 120.
enunciado.de: n verschiedene Teile lassen sich in n! Reihenfolgen einbauen: n! = 1 · 2 · … · n, und 0! ist 1. Gib n! als long zurück. Beispiel: factorial(5) gibt 120 zurück.
enunciado.en: n different parts can be fitted in n! orders: n! = 1 · 2 · … · n, and 0! is 1. Return n! as a long. Example: factorial(5) returns 120.
pista.es: Como sumar, pero multiplicando: empieza en long resultado = 1; y haz resultado *= i; para i de 2 a n.
pista.de: Wie beim Addieren, nur mit Malnehmen: fang mit long resultado = 1; an und rechne resultado *= i; für i von 2 bis n.
pista.en: Like adding up, but multiplying: start with long resultado = 1; and do resultado *= i; for i from 2 to n.
firma: static long factorial(int n)
plantilla:
    return 1;
solucion:
    long resultado = 1;
    for (int i = 2; i <= n; i++) {
        resultado *= i;
    }
    return resultado;

    factorial(0) => 1L
    factorial(1) => 1L
    factorial(10) => 3628800L

enunciado.es: Devuelve cuántas cifras tiene n. El 0 tiene una cifra y el signo no cuenta. Ejemplo: cuantasCifras(12345) devuelve 5 y cuantasCifras(-42), 2.
enunciado.de: Gib zurück, wie viele Ziffern n hat. Die 0 hat eine Ziffer, und das Vorzeichen zählt nicht. Beispiel: cuantasCifras(12345) gibt 5 zurück, cuantasCifras(-42) 2.
enunciado.en: Return how many digits n has. 0 has one digit and the sign doesn't count. Example: cuantasCifras(12345) returns 5 and cuantasCifras(-42) returns 2.
pista.es: Cada / 10 quita una cifra. Un do { ... } while (resto != 0); se ejecuta al menos una vez, justo lo que hace falta para el 0.
pista.de: Jedes / 10 entfernt eine Ziffer. Ein do { ... } while (resto != 0); läuft mindestens einmal – genau das, was du für die 0 brauchst.
pista.en: Each / 10 removes a digit. A do { ... } while (resto != 0); runs at least once, which is exactly what 0 needs.
firma: static int cuantasCifras(int n)
plantilla:
    return 0;
solucion:
    int cifras = 0;
    int resto = n;
    do {
        cifras++;
        resto /= 10;
    } while (resto != 0);
    return cifras;

    cuantasCifras(0) => 1

enunciado.de: Roboter in limitierter Auflage haben eine Primzahl als Seriennummer: größer als 1 und nur durch 1 und sich selbst teilbar. Gib true zurück, wenn n eine Primzahl ist. Beispiel: esPrimo(17) gibt true zurück, esPrimo(21) false.
enunciado.en: Limited-edition robots have a prime serial number: greater than 1 and only divisible by 1 and itself. Return true if n is prime. Example: esPrimo(17) returns true and esPrimo(21) false.
pista.es: Descarta antes los menores que 2. Luego prueba divisores desde 2; basta con llegar a i * i <= n. En cuanto uno divida, return false.
pista.de: Sortier zuerst alles unter 2 aus. Dann probier Teiler ab 2; es reicht bis i * i <= n. Sobald einer teilt: return false.
pista.en: Rule out anything below 2 first. Then try divisors from 2; going up to i * i <= n is enough. As soon as one divides, return false.
firma: static boolean esPrimo(int n)
plantilla:
    return false;
solucion:
    if (n < 2) {
        return false;
    }
    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            return false;
        }
    }
    return true;

enunciado.es: Dos engranajes tienen a y b dientes. Devuelve su máximo común divisor, el número más grande que divide a los dos. Ejemplo: mcd(12, 18) devuelve 6. Si uno es 0, el mcd es el otro.
enunciado.de: Zwei Zahnräder haben a und b Zähne. Gib ihren größten gemeinsamen Teiler zurück, die größte Zahl, die beide teilt. Beispiel: mcd(12, 18) gibt 6 zurück. Ist eine der Zahlen 0, ist der ggT die andere.
enunciado.en: Two gears have a and b teeth. Return their greatest common divisor, the biggest number that divides both. Example: mcd(12, 18) returns 6. If one of them is 0, the gcd is the other one.
pista.es: El algoritmo de Euclides: mientras b no sea 0, cambia (a, b) por (b, a % b). Cuando b llega a 0, la respuesta es a.
pista.de: Der euklidische Algorithmus: Solange b nicht 0 ist, ersetze (a, b) durch (b, a % b). Wenn b bei 0 ankommt, ist a die Antwort.
pista.en: Euclid's algorithm: while b isn't 0, replace (a, b) with (b, a % b). When b reaches 0, the answer is a.
firma: static int mcd(int a, int b)
plantilla:
    return 1;
solucion:
    while (b != 0) {
        int resto = a % b;
        a = b;
        b = resto;
    }
    return a;
casos:

    mcd(100, 75) => 25
    mcd(7, 5) => 1
    mcd(10, 10) => 10
    mcd(0, 9) => 9
    mcd(9, 0) => 9

    return resultado;

=== t05_rombo
tema: 05
dificultad: 5
java: 8
tipo: salida
titulo.es: El rombo del emblema
titulo.de: Die Raute im Wappen
titulo.en: The emblem diamond
enunciado.es: Dibuja un rombo de asteriscos cuya fila del medio tiene 2·n - 1. Cada fila está centrada con espacios a la izquierda (no a la derecha). Ejemplo: rombo(2) imprime " *", "***" y " *". Con n = 0, nada.
enunciado.de: Zeichne eine Raute aus Sternchen, deren mittlere Zeile 2·n - 1 hat. Jede Zeile wird mit Leerzeichen links (nicht rechts) zentriert. Beispiel: rombo(2) gibt " *", "***" und " *" aus. Bei n = 0 nichts.
enunciado.en: Draw a diamond of asterisks whose middle row has 2·n - 1 of them. Each row is centred with spaces on the left (not on the right). Example: rombo(2) prints " *", "***" and " *". With n = 0, nothing.
pista.es: Recorre las filas con i de -(n - 1) a n - 1. En cada una van Math.abs(i) espacios y 2 * (n - Math.abs(i)) - 1 asteriscos.
pista.de: Lauf mit i von -(n - 1) bis n - 1 über die Zeilen. In jede Zeile kommen Math.abs(i) Leerzeichen und 2 * (n - Math.abs(i)) - 1 Sternchen.
pista.en: Loop over the rows with i from -(n - 1) to n - 1. Each row gets Math.abs(i) spaces and 2 * (n - Math.abs(i)) - 1 asterisks.
firma: static void rombo(int n)
plantilla:
    System.out.println("*");
solucion:
    for (int i = 1 - n; i < n; i++) {
        int espacios = Math.abs(i);
        int asteriscos = 2 * (n - espacios) - 1;
        for (int k = 0; k < espacios; k++) {
            System.out.print(" ");
        }
        for (int k = 0; k < asteriscos; k++) {
            System.out.print("*");
        }
        System.out.println();
    }
casos:
    rombo(2); => " *\n***\n *\n"
    rombo(3); => "  *\n ***\n*****\n ***\n  *\n"
    rombo(1); => "*\n"
    rombo(0); => ""
