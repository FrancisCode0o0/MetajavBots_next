enunciado.es: Los double no son exactos: 0.1 + 0.2 no es exactamente 0.3. Devuelve true si a y b se diferencian en menos de 0.000001. Ejemplo: mismaEnergia(0.1 + 0.2, 0.3) devuelve true.
enunciado.de: double-Werte sind nicht exakt: 0.1 + 0.2 ist nicht genau 0.3. Gib true zurück, wenn sich a und b um weniger als 0.000001 unterscheiden. Beispiel: mismaEnergia(0.1 + 0.2, 0.3) gibt true zurück.
enunciado.en: doubles are not exact: 0.1 + 0.2 is not exactly 0.3. Return true if a and b differ by less than 0.000001. Example: mismaEnergia(0.1 + 0.2, 0.3) returns true.
pista.es: Nunca compares decimales con ==. Mira la distancia entre ellos: Math.abs(a - b) < 0.000001 (o 1e-6).
pista.de: Vergleiche Kommazahlen nie mit ==. Schau dir ihren Abstand an: Math.abs(a - b) < 0.000001 (oder 1e-6).
pista.en: Never compare decimals with ==. Look at the distance between them: Math.abs(a - b) < 0.000001 (or 1e-6).
firma: static boolean mismaEnergia(double a, double b)

    return a == b;
solucion:

    return Math.abs(a - b) < TOLERANCIA;

    mismaEnergia(1.0, 1.0) => true
    mismaEnergia(1.0, 1.1) => false
    mismaEnergia(-0.5, 0.5) => false
    mismaEnergia(2.0000000001, 2.0) => true

=== t02_suma_saturada
tema: 02
dificultad: 5
java: 8
tipo: metodo
titulo.es: Una suma que se queda en el tope
titulo.de: Eine Summe, die am Anschlag stehen bleibt
titulo.en: A sum that stops at the limit
enunciado.es: Suma a y b, pero si el resultado no cabe en un int, devuelve el tope: Integer.MAX_VALUE si se pasa por arriba e Integer.MIN_VALUE si se pasa por abajo. Ejemplo: sumaSaturada(Integer.MAX_VALUE, 1) devuelve Integer.MAX_VALUE.
enunciado.de: Addiere a und b, aber wenn das Ergebnis nicht in einen int passt, gib die Grenze zurück: Integer.MAX_VALUE, wenn es oben überläuft, und Integer.MIN_VALUE, wenn es unten überläuft. Beispiel: sumaSaturada(Integer.MAX_VALUE, 1) gibt Integer.MAX_VALUE zurück.
enunciado.en: Add a and b, but if the result doesn't fit in an int, return the limit: Integer.MAX_VALUE if it goes over the top and Integer.MIN_VALUE if it goes below the bottom. Example: sumaSaturada(Integer.MAX_VALUE, 1) returns Integer.MAX_VALUE.
pista.es: Suma en un long, donde sí cabe: long suma = (long) a + b; Luego recórtala con Math.min y Math.max y vuelve a int con un cast.
pista.de: Rechne in einem long, da passt es: long suma = (long) a + b; Dann begrenze mit Math.min und Math.max und mach mit einem Cast wieder einen int daraus.
pista.en: Add in a long, where it fits: long suma = (long) a + b; Then clip it with Math.min and Math.max and cast it back to int.
firma: static int sumaSaturada(int a, int b)
plantilla:
    return a + b;
solucion:
    long suma = (long) a + b;
    long recortada = Math.max(Integer.MIN_VALUE, Math.min(Integer.MAX_VALUE, suma));
    return (int) recortada;
casos:
    sumaSaturada(2, 3) => 5
    sumaSaturada(Integer.MAX_VALUE, 1) => Integer.MAX_VALUE
    sumaSaturada(Integer.MIN_VALUE, -1) => Integer.MIN_VALUE
    sumaSaturada(Integer.MAX_VALUE, Integer.MAX_VALUE) => Integer.MAX_VALUE
    sumaSaturada(-7, 7) => 0
    sumaSaturada(Integer.MAX_VALUE, -1) => 2147483646
