enunciado.de: Die Übungspuppe steht dx rechts und dy oberhalb deines Roboters. Gib den Winkel zu ihr in ganzen Grad zurück (0 = rechts, 90 = oben, 180 = links, -90 = unten).

pista.es: Math.atan2(dy, dx) da el ángulo en radianes (¡ojo al orden: primero dy!). ¿Qué método de Math pasa radianes a grados? Luego, redondea.

pista.en: Math.atan2(dy, dx) gives the angle in radians (mind the order: dy first!). Which Math method turns radians into degrees? Then round.

=== j_normalizar
tema: 04
dificultad: 2
java: 8
tipo: metodo
escena: giro
titulo.es: Ángulos sin vueltas de más
titulo.de: Winkel ohne Extradrehungen
titulo.en: Angles without extra spins
enunciado.es: Un robot que gira 370° da una vuelta entera para nada. Devuelve el mismo ángulo entre -179 y 180 (370 → 10, 190 → -170, -190 → 170).
enunciado.de: Ein Roboter, der sich um 370° dreht, macht eine ganze Umdrehung umsonst. Gib denselben Winkel zwischen -179 und 180 zurück (370 → 10, 190 → -170, -190 → 170).
enunciado.en: A robot that turns 370° spins a whole circle for nothing. Return the same angle between -179 and 180 (370 → 10, 190 → -170, -190 → 170).
pista.es: El resto (%) de dividir entre 360 quita las vueltas enteras. ¿Y qué haces si aún queda más de 180, o 180 o menos en negativo?
pista.de: Der Rest (%) beim Teilen durch 360 entfernt die ganzen Umdrehungen. Und was tust du, wenn danach noch mehr als 180 übrig ist, oder -180 und weniger?
pista.en: The remainder (%) of dividing by 360 removes whole turns. And what do you do if more than 180 is still left, or -180 and below?
firma: static int normalizar(int grados)
plantilla:
    return grados;
solucion:
    int g = grados % 360;
    if (g > 180) g -= 360;
    if (g <= -180) g += 360;
    return g;
casos:
    normalizar(370) => 10
    normalizar(190) => -170
    normalizar(-190) => 170
    normalizar(360) => 0
    normalizar(540) => 180
    normalizar(-180) => 180
    normalizar(45) => 45

titulo.es: El giro más corto
titulo.de: Die kürzeste Drehung

enunciado.es: Tu robot mira hacia «rumbo» y el enemigo está hacia «haciaEnemigo» (los dos en grados, de 0 a 359). Devuelve cuánto girar por el camino más corto: positivo a la izquierda, negativo a la derecha, entre -179 y 180.
enunciado.de: Dein Roboter schaut nach „rumbo“, der Gegner steht in Richtung „haciaEnemigo“ (beides in Grad, 0 bis 359). Gib zurück, wie weit du dich auf dem kürzesten Weg drehen musst: positiv nach links, negativ nach rechts, zwischen -179 und 180.
enunciado.en: Your robot faces “rumbo” and the enemy is toward “haciaEnemigo” (both in degrees, 0 to 359). Return how far to turn the shortest way: positive to the left, negative to the right, between -179 and 180.
pista.es: La diferencia es haciaEnemigo - rumbo. Pero de 350 a 10 no hay que girar -340… ¿qué ejercicio anterior te arregla eso?
pista.de: Die Differenz ist haciaEnemigo - rumbo. Aber von 350 nach 10 dreht man nicht -340 … welche frühere Übung repariert das?
pista.en: The difference is haciaEnemigo - rumbo. But from 350 to 10 you don't turn -340… which earlier exercise fixes that?
firma: static int cuantoGirar(int rumbo, int haciaEnemigo)
plantilla:
    return haciaEnemigo - rumbo;
solucion:
    int g = (haciaEnemigo - rumbo) % 360;
    if (g > 180) g -= 360;
    if (g <= -180) g += 360;
    return g;
casos:

    cuantoGirar(350, 10) => 20
    cuantoGirar(10, 350) => -20
    cuantoGirar(90, 270) => 180
    cuantoGirar(45, 45) => 0

=== j_elegir_brazo
tema: 04
dificultad: 2
java: 8
tipo: metodo
titulo.es: ¿Con qué brazo?
titulo.de: Mit welchem Arm?
titulo.en: Which arm?
enunciado.es: Devuelve el brazo con el que pegar: el que llegue al enemigo; si llegan los dos, el de menos alcance (pega más fuerte de cerca); si ninguno, "ninguno". Los nombres: "izquierda", "derecha", "ninguno".
enunciado.de: Gib den Arm zurück, mit dem du zuschlägst: den, der den Gegner erreicht; erreichen ihn beide, den mit weniger Reichweite (der schlägt aus der Nähe härter); keiner, dann "keiner". Die Namen: "links", "rechts", "keiner".
enunciado.en: Return the arm to hit with: the one that reaches the enemy; if both do, the one with the shorter range (it hits harder up close); if neither, "none". The names: "left", "right", "none".
pista.es: Primero guarda en dos boolean si llega cada brazo. Luego piensa los cuatro casos: los dos, solo uno, solo el otro, ninguno.
pista.de: Speichere zuerst in zwei boolean, ob jeder Arm hinkommt. Dann denk an die vier Fälle: beide, nur einer, nur der andere, keiner.
pista.en: First store in two booleans whether each arm reaches. Then think through the four cases: both, only one, only the other, neither.
firma: static String elegirBrazo(double distancia, double alcanceIzq, double alcanceDer)
plantilla:
    return "ninguno";
solucion:
    boolean izq = distancia <= alcanceIzq, der = distancia <= alcanceDer;
    if (izq && der) return alcanceIzq <= alcanceDer ? "izquierda" : "derecha";
    if (izq) return "izquierda";
    if (der) return "derecha";
    return "ninguno";
casos:
    elegirBrazo(50, 80, 400) => "izquierda"
    elegirBrazo(300, 80, 400) => "derecha"
    elegirBrazo(500, 80, 400) => "ninguno"
    elegirBrazo(50, 400, 80) => "derecha"
terminos.de:
    "izquierda" ==> "links"
    "derecha" ==> "rechts"
    "ninguno" ==> "keiner"
terminos.en:
    "izquierda" ==> "left"
    "derecha" ==> "right"
    "ninguno" ==> "none"

=== j_mas_cercano
tema: 07
dificultad: 2
java: 8
tipo: metodo
titulo.es: Leer al enemigo: el más cercano
titulo.de: Den Gegner lesen: der nächste
titulo.en: Reading the enemy: the closest
enunciado.es: El radar te da las distancias de los enemigos que ve. Devuelve la posición (el índice) del más cercano, o -1 si no ve a nadie.
enunciado.de: Das Radar liefert die Abstände der Gegner, die es sieht. Gib die Position (den Index) des nächsten zurück, oder -1, wenn es niemanden sieht.
enunciado.en: The radar gives you the distances of the enemies it sees. Return the position (the index) of the closest, or -1 if it sees no one.
pista.es: Recorre el array guardando el índice del mejor hasta ahora. ¿Con qué valor empiezas para que el array vacío dé -1?
pista.de: Geh das Array durch und merk dir den Index des bisher besten. Mit welchem Wert fängst du an, damit das leere Array -1 ergibt?
pista.en: Walk the array keeping the index of the best so far. What value do you start with so the empty array gives -1?
firma: static int masCercano(double[] distancias)
plantilla:
    return 0;
solucion:
    int mejor = -1;
    for (int i = 0; i < distancias.length; i++) {
        if (mejor < 0 || distancias[i] < distancias[mejor]) mejor = i;
    }
    return mejor;
casos:
    masCercano(new double[]{300, 120, 450}) => 1
    masCercano(new double[]{}) => -1
    masCercano(new double[]{80}) => 0
    masCercano(new double[]{90, 90, 30, 31}) => 2

=== j_memoria_huidas
tema: 15
dificultad: 3
java: 8
tipo: metodo
titulo.es: Memoria entre rondas
titulo.de: Gedächtnis zwischen den Runden
titulo.en: Memory between rounds
enunciado.es: memoria() es un Map que dura toda la pelea. Cada vez que el rival huye por la izquierda, súmale uno a la clave "izq" (empieza en 0 si no está) y devuelve cuántas veces lleva.
enunciado.de: gedaechtnis() ist eine Map, die den ganzen Kampf über hält. Jedes Mal, wenn der Gegner nach links flieht, erhöhe den Schlüssel "links" um eins (bei 0 anfangen, wenn er fehlt) und gib zurück, wie oft schon.
enunciado.en: memory() is a Map that lasts the whole fight. Each time the rival flees to the left, add one to the key "left" (start at 0 if missing) and return how many times so far.
pista.es: getOrDefault te da el valor o uno por defecto. Y no olvides volver a guardarlo con put: si no, la memoria no se entera.
pista.de: getOrDefault liefert den Wert oder einen Standardwert. Und vergiss nicht, ihn mit put wieder zu speichern, sonst merkt sich das Gedächtnis nichts.
pista.en: getOrDefault gives you the value or a default. And don't forget to store it back with put, or the memory won't know.
firma: static int huidas(java.util.Map<String, Object> memoria, boolean porLaIzquierda)
plantilla:
    return 0;
solucion:
    int n = (Integer) memoria.getOrDefault("izq", 0);
    if (porLaIzquierda) {
        n++;
        memoria.put("izq", n);
    }
    return n;
casos:
    huidas(new java.util.HashMap<>(java.util.Map.of("izq", 2)), true) => 3
    huidas(new java.util.HashMap<>(), true) => 1
    huidas(new java.util.HashMap<>(), false) => 0
    huidas(new java.util.HashMap<>(java.util.Map.of("izq", 5)), false) => 5
terminos.de:
    "izq" ==> "links"
terminos.en:
    "izq" ==> "left"

=== j_dos_ordenes_cabeza
tema: 04
dificultad: 2
java: 8
tipo: metodo
escena: giro
titulo.es: Dos órdenes para la cabeza
titulo.de: Zwei Befehle für den Kopf
titulo.en: Two orders for the head
enunciado.es: En el mismo turno, alVerEnemigo pide apuntar(primera) y después cadaTurno pide apuntar(segunda). La cabeza (la mira) solo recuerda la última orden y gira como mucho 14° por turno. Empieza mirando hacia «mira»: devuelve hacia dónde mira al acabar el turno.
enunciado.de: Im selben Zug verlangt beiSicht zielen(primera) und danach jedenZug zielen(segunda). Der Kopf (das Visier) merkt sich nur den letzten Befehl und dreht sich höchstens 14° pro Zug. Er schaut am Anfang nach „mira“: Gib zurück, wohin er am Ende des Zugs schaut.
enunciado.en: In the same tick, onSeeEnemy asks for aim(primera) and then onTick asks for aim(segunda). The head (the sight) remembers only the last order and turns at most 14° per tick. It starts looking toward “mira”: return where it looks at the end of the tick.
pista.es: Primero piensa cuál de las dos órdenes manda. Después: si pide girar más de 14° (o menos de -14°), ¿cuánto gira de verdad en un turno?
pista.de: Überleg zuerst, welcher der beiden Befehle zählt. Dann: Wenn er mehr als 14° (oder weniger als -14°) drehen soll, wie weit dreht er sich in einem Zug wirklich?
pista.en: First think about which of the two orders wins. Then: if it asks to turn more than 14° (or less than -14°), how far does it really turn in one tick?
firma: static int miraFinal(int mira, int primera, int segunda)
plantilla:
    return mira + primera;
solucion:
    int giro = Math.max(-14, Math.min(14, segunda));
    return mira + giro;
casos:
    miraFinal(0, 90, 12) => 12
    miraFinal(0, 12, 90) => 14
    miraFinal(30, -5, -40) => 16
    miraFinal(45, 60, 0) => 45
    miraFinal(-20, 0, -8) => -28
