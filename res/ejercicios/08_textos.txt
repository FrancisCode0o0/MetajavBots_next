pista.es: trim() y después split("\\s+") parte por uno o más espacios. Para cada palabra no vacía, añade Character.toUpperCase(palabra.charAt(0)) a un StringBuilder.

enunciado.en: Count how many times palabra appears inside registro, without overlapping (in "aaaa", "aa" appears 2 times) and case-sensitive. palabra is never empty.
pista.es: indexOf(palabra, desde) busca a partir de una posición y da -1 si ya no hay más. Tras encontrarla, sigue buscando desde la posición + palabra.length().
pista.de: indexOf(palabra, desde) sucht ab einer Position und liefert -1, wenn nichts mehr kommt. Nach einem Fund suchst du ab Position + palabra.length() weiter.
pista.en: indexOf(palabra, desde) searches from a position and returns -1 when there are no more. After a match, keep searching from the position + palabra.length().

    return 0;
solucion:
    int veces = 0;
    int posicion = registro.indexOf(palabra);
    while (posicion >= 0) {
        veces++;
        posicion = registro.indexOf(palabra, posicion + palabra.length());
    }
    return veces;

=== t08_comprimir_senal
tema: 08
dificultad: 4
java: 8
tipo: metodo
titulo.es: Comprimir la señal del radar
titulo.de: Das Radarsignal komprimieren
titulo.en: Compress the radar signal
enunciado.es: El radar manda señales con muchos caracteres repetidos seguidos. Comprime cada grupo de caracteres iguales seguidos en el carácter y cuántas veces sale: "...***.." da ".3*3.2" y "x" da "x1".
enunciado.de: Das Radar sendet Signale mit vielen gleichen Zeichen hintereinander. Fasse jede Gruppe gleicher, aufeinanderfolgender Zeichen zu dem Zeichen und seiner Anzahl zusammen: "...***.." ergibt ".3*3.2" und "x" ergibt "x1".
enunciado.en: The radar sends signals with many repeated characters in a row. Compress each run of equal consecutive characters into the character and how many times it appears: "...***.." gives ".3*3.2" and "x" gives "x1".
pista.es: Recorre el texto; para cada posición, avanza otro índice mientras el carácter sea el mismo. La longitud del grupo es fin - inicio.
pista.de: Geh den Text durch; schiebe für jede Position einen zweiten Index weiter, solange das Zeichen gleich bleibt. Die Gruppenlänge ist Ende - Anfang.
pista.en: Walk through the text; for each position, move a second index forward while the character stays the same. The run length is end - start.
firma: static String comprimir(String senal)
plantilla:
    return senal;
solucion:
    StringBuilder resultado = new StringBuilder();
    int inicio = 0;
    while (inicio < senal.length()) {
        char actual = senal.charAt(inicio);
        int fin = inicio;
        while (fin < senal.length() && senal.charAt(fin) == actual) {
            fin++;
        }
        resultado.append(actual).append(fin - inicio);
        inicio = fin;
    }
    return resultado.toString();
casos:
    comprimir("...***..") => ".3*3.2"
    comprimir("x") => "x1"
    comprimir("") => ""
    comprimir("aaaaaaaaaaaa") => "a12"
    comprimir("abab") => "a1b1a1b1"

            resultado.append(c);
        }

pista.es: Lleva la cuenta del largo de la línea actual. Antes de añadir una palabra, mira si largo + 1 + palabra.length() se pasa de ancho: entonces toca "\n" en lugar del espacio.
pista.de: Merk dir die Länge der aktuellen Zeile. Prüfe vor jedem Wort, ob Länge + 1 + palabra.length() über ancho kommt: Dann kommt "\n" statt des Leerzeichens.
pista.en: Keep track of the current line's length. Before adding a word, check whether length + 1 + palabra.length() goes over ancho: then write "\n" instead of the space.
firma: static String ajustar(String texto, int ancho)
plantilla:
    return texto;
solucion:
    StringBuilder resultado = new StringBuilder();
    int largoDeLinea = 0;
    for (String palabra : texto.trim().split("\\s+")) {
        if (palabra.isEmpty()) {
            continue;
        }
        if (largoDeLinea > 0 && largoDeLinea + 1 + palabra.length() > ancho) {
            resultado.append('\n');
            largoDeLinea = 0;
        } else if (largoDeLinea > 0) {
            resultado.append(' ');
            largoDeLinea++;
        }
        resultado.append(palabra);
        largoDeLinea += palabra.length();
    }
    return resultado.toString();
casos:
    ajustar("el robot rojo gana", 9) => "el robot\nrojo gana"
    ajustar("a b c", 1) => "a\nb\nc"
    ajustar("misil", 3) => "misil"
    ajustar("  uno   dos ", 20) => "uno dos"
    ajustar("", 5) => ""
    ajustar("ok megalaser ok", 4) => "ok\nmegalaser\nok"
