enunciado.es: Java 15 trajo los bloques de texto: un texto de varias líneas entre """ y """. Úsalo para imprimir estas cuatro líneas: +---------+, |  ARENA  |, +---------+ y Robot: seguido del nombre. Ejemplo: cartel("Chispa") termina con Robot: Chispa.
enunciado.de: Java 15 hat Textblöcke eingeführt: ein mehrzeiliger Text zwischen """ und """. Gib damit diese vier Zeilen aus: +---------+, |  ARENA  |, +---------+ und Robot: gefolgt vom Namen. Beispiel: cartel("Chispa") endet mit Robot: Chispa.
enunciado.en: Java 15 introduced text blocks: a multi-line text between """ and """. Use one to print these four lines: +---------+, |  ARENA  |, +---------+ and Robot: followed by the name. Example: cartel("Chispa") ends with Robot: Chispa.
pista.es: Abre con """ y salta de línea; la sangría común se quita sola. Pon %s donde va el nombre y rellénalo con .formatted(nombre), también de Java 15.
pista.de: Öffne mit """ und mach einen Zeilenumbruch; die gemeinsame Einrückung fällt von selbst weg. Setz %s für den Namen ein und füll ihn mit .formatted(nombre), ebenfalls seit Java 15.
pista.en: Open with """ and a line break; the common indentation is removed for you. Put %s where the name goes and fill it with .formatted(nombre), also from Java 15.
firma: static void cartel(String nombre)
plantilla:
    // usa un bloque de texto: """ ... """
    System.out.println("Robot: " + nombre);
solucion:

            +---------+
            |  ARENA  |
            +---------+
            Robot: %s""".formatted(nombre);
    System.out.println(cartel);
