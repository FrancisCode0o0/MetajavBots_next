=== t16_caja_de_piezas
tema: 16
dificultad: 1

tipo: clase
titulo.es: Una caja para cualquier pieza
titulo.de: Eine Kiste für jedes Teil
titulo.en: A box for any part
enunciado.es: La clase Caja guarda su contenido como Object y obliga a hacer casts. Hazla genérica (los genéricos llegaron en Java 5): Caja<T> con el constructor Caja(T contenido), T sacar() y boolean estaVacia() (true si el contenido es null). Mach sie generisch (Generics gibt es seit Java 5): Caja<T> mit dem Konstruktor Caja(T contenido), T sacar() und boolean estaVacia() (true, wenn der Inhalt null ist). Dann klappt new Caja<>("laser") mit dem Diamant-Operator aus Java 7.
enunciado.en: The Caja class stores its content as Object and forces you to cast. Make it generic (generics arrived in Java 5): Caja<T> with the constructor Caja(T contenido), T sacar() and boolean estaVacia() (true when the content is null). Then new Caja<>("laser") works with the diamond operator from Java 7.
pista.es: Escribe public class Caja<T> y cambia Object por T en el campo, el constructor y sacar().
pista.de: Schreib public class Caja<T> und ersetze Object durch T im Feld, im Konstruktor und in sacar().
pista.en: Write public class Caja<T> and replace Object with T in the field, the constructor and sacar().
plantilla:
    public class Caja {
        private final Object contenido;

        public Caja(Object contenido) {
            this.contenido = contenido;
        }

        public Object sacar() {
            return contenido;
        }

        public boolean estaVacia() {
            return false;
        }
    }
solucion:
    public class Caja<T> {
        private final T contenido;

        public Caja(T contenido) {
            this.contenido = contenido;
        }

        public T sacar() {
            return contenido;
        }

        public boolean estaVacia() {
            return contenido == null;
        }
    }

pista.de: Eine Klasse darf mehrere Typvariablen haben: class Par<A, B>. invertido() gibt new Par<>(segundo, primero) zurück. Seit Java 16 erledigt ein record Par<A, B>(A primero, B segundo) fast alles.

plantilla:
    public class Par<A, B> {
        // tus campos, tu constructor y tus métodos
    }
solucion:
    public class Par<A, B> {
        private final A primero;
        private final B segundo;

        public Par(A primero, B segundo) {
            this.primero = primero;
            this.segundo = segundo;
        }

        public A primero() {
            return primero;
        }

        public B segundo() {
            return segundo;
        }

        public Par<B, A> invertido() {
            return new Par<>(segundo, primero);
        }

        @Override
        public String toString() {
            return "(" + primero + ", " + segundo + ")";
        }
    }

    new Par<>(1, 'x').invertido().segundo() => 1
    new Par<>("a", 2.0).toString() => "(a, 2.0)"
    new Par<>(null, "b").invertido().toString() => "(b, null)"

=== t16_maximo_acotado
tema: 16
dificultad: 3
java: 5
tipo: metodo
titulo.es: El mayor de cualquier cosa comparable
titulo.de: Das Größte von allem Vergleichbaren
titulo.en: The largest of anything comparable
enunciado.es: Devuelve el mayor elemento de la lista. El tipo está acotado: T extends Comparable<? super T>, así que sirve para números, textos y fechas. Si la lista está vacía, lanza IllegalArgumentException.
enunciado.de: Gib das größte Element der Liste zurück. Der Typ ist beschränkt: T extends Comparable<? super T>, daher geht es für Zahlen, Texte und Datumswerte. Ist die Liste leer, wirf eine IllegalArgumentException.
enunciado.en: Return the largest element in the list. The type is bounded: T extends Comparable<? super T>, so it works for numbers, strings and dates. If the list is empty, throw an IllegalArgumentException.
pista.es: Empieza con el primero y recorre el resto: si x.compareTo(mayor) > 0, x es el nuevo mayor. El ? super T hace falta para LocalDate, que es Comparable<ChronoLocalDate>.
pista.de: Fang mit dem ersten an und geh den Rest durch: Wenn x.compareTo(mayor) > 0, ist x das neue Maximum. Das ? super T braucht man für LocalDate, das Comparable<ChronoLocalDate> ist.
pista.en: Start with the first one and walk the rest: if x.compareTo(mayor) > 0, x is the new maximum. The ? super T is needed for LocalDate, which is Comparable<ChronoLocalDate>.
firma: static <T extends Comparable<? super T>> T maximo(List<T> lista)
plantilla:
    return lista.get(0);
solucion:
    if (lista.isEmpty()) {
        throw new IllegalArgumentException("la lista está vacía");
    }
    T mayor = lista.get(0);
    for (T x : lista) {
        if (x.compareTo(mayor) > 0) {
            mayor = x;
        }
    }
    return mayor;
casos:
    maximo(List.of(3, 9, 4)) => 9
    maximo(List.of(-5, -2, -9)) => -2
    maximo(List.of("bala", "misil", "láser")) => "misil"
    maximo(List.of(java.time.LocalDate.of(2023, 5, 5), java.time.LocalDate.of(2024, 1, 1))) => java.time.LocalDate.of(2024, 1, 1)
    maximo(new ArrayList<Integer>()) => !IllegalArgumentException

=== t16_invertir_mapa
tema: 16
dificultad: 3
java: 8
tipo: metodo
titulo.es: ¿Quién juega en cada equipo?
titulo.de: Wer spielt in welchem Team?
titulo.en: Who plays on each team?
enunciado.es: El mapa dice el equipo de cada robot. Devuelve el mapa al revés: para cada valor, la lista de claves que lo tienen, en el orden en que las recorre el mapa original. Funciona con cualquier tipo de claves y valores.
enunciado.de: Die Map nennt das Team jedes Roboters. Gib sie umgedreht zurück: zu jedem Wert die Liste der Schlüssel, die ihn haben, in der Reihenfolge, in der die ursprüngliche Map sie durchläuft. Funktioniert mit beliebigen Schlüssel- und Werttypen.
enunciado.en: The map says which team each robot is on. Return it inverted: for each value, the list of keys that have it, in the order the original map iterates them. It works for any key and value types.
pista.es: Recorre mapa.entrySet() y usa resultado.computeIfAbsent(valor, v -> new ArrayList<>()).add(clave) (computeIfAbsent llegó en Java 8).
pista.de: Geh mapa.entrySet() durch und nutze resultado.computeIfAbsent(wert, v -> new ArrayList<>()).add(schluessel) (computeIfAbsent gibt es seit Java 8).
pista.en: Walk mapa.entrySet() and use resultado.computeIfAbsent(value, v -> new ArrayList<>()).add(key) (computeIfAbsent arrived in Java 8).
firma: static <K, V> Map<V, List<K>> invertir(Map<K, V> mapa)
plantilla:
    return new HashMap<>();
solucion:
    Map<V, List<K>> resultado = new HashMap<>();
    for (Map.Entry<K, V> e : mapa.entrySet()) {
        resultado.computeIfAbsent(e.getValue(), v -> new ArrayList<>()).add(e.getKey());
    }
    return resultado;

    invertir(new TreeMap<>(Map.of(3, 'x', 1, 'x', 2, 'y'))) => Map.of('x', List.of(1, 3), 'y', List.of(2))
    invertir(Map.of(1, "solo")) => Map.of("solo", List.of(1))
    invertir(Map.of()) => Map.of()

pista.en: Step forward by tamano and copy each chunk with new ArrayList<>(lista.subList(i, Math.min(i + tamano, lista.size()))). In Java 24, gather(Gatherers.windowFixed(tamano)) does the same with streams.
firma: static <T> List<List<T>> enTrozos(List<T> lista, int tamano)

    trozos.add(lista);
    return trozos;

    if (tamano < 1) {
        throw new IllegalArgumentException("tamaño no válido: " + tamano);
    }
    List<List<T>> trozos = new ArrayList<>();
    for (int i = 0; i < lista.size(); i += tamano) {
        trozos.add(new ArrayList<>(lista.subList(i, Math.min(i + tamano, lista.size()))));
    }
    return trozos;

enunciado.de: Schreib Pila<T> implements Iterable<T>: Pila<T> apilar(T cosa) (gibt this zum Verketten zurück), T desapilar() und T cima() (beide werfen IllegalStateException, wenn der Stapel leer ist), int tamano() und boolean estaVacia(). Beim Durchlaufen kommt das oberste Element zuerst.
enunciado.en: Write Pila<T> implements Iterable<T>: Pila<T> apilar(T cosa) (returns this for chaining), T desapilar() and T cima() (both throw IllegalStateException when empty), int tamano() and boolean estaVacia(). When iterating, the top comes first.
pista.es: Guarda los elementos en un ArrayDeque<T> (Java 6): push, pop y peek trabajan por delante, y su iterator() ya empieza por la cima.
pista.de: Speichere die Elemente in einer ArrayDeque<T> (Java 6): push, pop und peek arbeiten vorne, und ihr iterator() beginnt schon oben.
pista.en: Keep the elements in an ArrayDeque<T> (Java 6): push, pop and peek work at the front, and its iterator() already starts at the top.
plantilla:
    import java.util.*;

    public class Pila<T> implements Iterable<T> {

        public Pila<T> apilar(T cosa) {
            return this;
        }

        public T desapilar() {
            return null;
        }

        public T cima() {
            return null;
        }

        public int tamano() {
            return 0;
        }

        public boolean estaVacia() {
            return true;
        }

        @Override
        public Iterator<T> iterator() {
            return Collections.emptyIterator();
        }
    }
solucion:
    import java.util.ArrayDeque;
    import java.util.Deque;
    import java.util.Iterator;

    public class Pila<T> implements Iterable<T> {
        private final Deque<T> elementos = new ArrayDeque<>();

        public Pila<T> apilar(T cosa) {
            elementos.push(cosa);
            return this;
        }

        public T desapilar() {
            comprobarQueNoEstaVacia();
            return elementos.pop();
        }

        public T cima() {
            comprobarQueNoEstaVacia();
            return elementos.peek();
        }

        public int tamano() {
            return elementos.size();
        }

        public boolean estaVacia() {
            return elementos.isEmpty();
        }

        @Override
        public Iterator<T> iterator() {
            return elementos.iterator();
        }

        private void comprobarQueNoEstaVacia() {
            if (elementos.isEmpty()) {
                throw new IllegalStateException("la pila está vacía");
            }
        }
    }

    new Pila<String>().apilar("chasis").apilar("brazo").cima() => "brazo"
    new Pila<Integer>().apilar(1).apilar(2).apilar(3).tamano() => 3

    new Pila<String>().cima() => !IllegalStateException
    String.join(",", new Pila<String>().apilar("a").apilar("b").apilar("c")) => "c,b,a"

    import java.util.ArrayList;
    import java.util.List;
    import java.util.Map;
    import java.util.Optional;
    import java.util.TreeMap;

    interface ConCodigo {
        String codigo();
    }

    record Pieza(String codigo, int peso) implements ConCodigo {
    }

    public class Almacen<T extends ConCodigo> {
        private final Map<String, T> porCodigo = new TreeMap<>();

        public Almacen<T> guardar(T cosa) {
            porCodigo.put(cosa.codigo(), cosa);
            return this;
        }

            return Optional.ofNullable(porCodigo.get(codigo));
        }

            return porCodigo.size();
        }

        public List<T> todos() {
            return new ArrayList<>(porCodigo.values());
        }
    }

titulo.es: El mejor según lo que tú digas
titulo.de: Das Beste nach deinem Maßstab
titulo.en: The best by your own measure
enunciado.es: Devuelve el elemento de la lista cuya clave (la que calcula la función clave) es la mayor. Si hay empate, el primero. Si la lista está vacía, null. La firma usa dos variables de tipo y comodines: así sirve para cualquier elemento y cualquier clave comparable.

solucion:
    import java.util.HashMap;
    import java.util.Map;
    import java.util.Objects;

    public class Inventario {
        private final Map<Class<?>, Object> cosas = new HashMap<>();

        public <T> Inventario poner(Class<T> tipo, T valor) {
            cosas.put(Objects.requireNonNull(tipo), tipo.cast(valor));
            return this;
        }

        public <T> T sacar(Class<T> tipo) {
            return tipo.cast(cosas.get(tipo));
        }

        public int tamano() {
            return cosas.size();
        }
    }
