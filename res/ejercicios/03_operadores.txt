=== t03_tiene_mejora
tema: 03
dificultad: 5
java: 8
tipo: metodo
titulo.es: Mejoras guardadas en bits
titulo.de: In Bits gespeicherte Upgrades
titulo.en: Upgrades stored in bits
enunciado.es: El robot guarda sus mejoras en los bits de un int: el bit 0 (valor 1) es el láser, el bit 1 (valor 2) el escudo, el bit 2 (valor 4) el turbo… Devuelve true si el bit numero está a 1. Ejemplo: tieneMejora(5, 2) devuelve true, porque 5 es 101 en binario.
enunciado.de: Der Roboter speichert seine Upgrades in den Bits eines int: Bit 0 (Wert 1) ist der Laser, Bit 1 (Wert 2) der Schild, Bit 2 (Wert 4) der Turbo … Gib true zurück, wenn Bit numero auf 1 steht. Beispiel: tieneMejora(5, 2) gibt true zurück, denn 5 ist binär 101.
enunciado.en: The robot stores its upgrades in the bits of an int: bit 0 (value 1) is the laser, bit 1 (value 2) the shield, bit 2 (value 4) the turbo… Return true if bit numero is set to 1. Example: tieneMejora(5, 2) returns true, because 5 is 101 in binary.
pista.es: 1 << numero es un número con solo ese bit encendido. & deja los bits que están en los dos: (mejoras & (1 << numero)) != 0.
pista.de: 1 << numero ist eine Zahl, bei der nur dieses Bit gesetzt ist. & behält die Bits, die in beiden gesetzt sind: (mejoras & (1 << numero)) != 0.
pista.en: 1 << numero is a number with only that bit set. & keeps the bits that are set in both: (mejoras & (1 << numero)) != 0.
firma: static boolean tieneMejora(int mejoras, int numero)
plantilla:
    return false;
solucion:
    int mascara = 1 << numero;
    return (mejoras & mascara) != 0;
casos:
    tieneMejora(5, 0) => true
    tieneMejora(5, 1) => false
    tieneMejora(5, 2) => true
    tieneMejora(8, 3) => true
    tieneMejora(0, 3) => false
    tieneMejora(-1, 31) => true
