# PAQUETES — Documentación estilo Javadoc de los paquetes y clases permitidos en MetajavBots.
# Alineado con Vigilante.java y Cargador.java: no documenta nada que la caja de arena bloquee.
# Formato:
#   === paquete <nombre>
#   import: <sentencia import de ejemplo, o "(automático)">
#   auto: true|false           (si Java lo importa automáticamente, como java.lang)
#   plantilla: true|false      (si ya viene en la plantilla del robot, como metajavbots.api)
#   solo_ejercicio: true|false (si el paquete es solo para ejercicios/laboratorio)
#   resumen.es / resumen.de / resumen.en
#   es: / de: / en:            (párrafos indentados con 4 espacios)
#   bloqueado.es / bloqueado.de / bloqueado.en  (opcional: qué clases/miembros del paquete están bloqueados)
#
#   --- <IdComponente>
#   nombre.es / nombre.de / nombre.en   (opcional: para clases de metajavbots.api traducidas por idioma)
#   tipo: clase|interfaz|enum|anotacion|excepcion|error
#   solo_ejercicio: true|false          (opcional: bloqueado en robots, permitido en ejercicios)
#   es: / de: / en:
#   miembros.es: / miembros.de: / miembros.en:   (un miembro por línea: «firma — propósito»)
#   ejemplo:                            (código Java; en metajavbots.api se traduce según idioma)

=== paquete metajavbots.api
import: import metajavbots.api.*;
auto: false
plantilla: true
solo_ejercicio: false
resumen.es: La API de los robots de combate: eventos, movimiento, radar, armas, memoria y límites de cálculo.
resumen.de: Die Roboter-API für Kämpfe: Ereignisse, Bewegung, Radar, Waffen, Gedächtnis und Rechenlimits.
resumen.en: The fighting robot API: events, movement, radar, weapons, memory and computation limits.
es:
    Paquete propio de MetajavBots con todo lo necesario para programar un robot de combate. Ya viene importado en la primera línea de todas las plantillas del Taller con «import metajavbots.api.*;».
    Según el idioma del juego cambian los nombres de la clase base y sus interfaces (Metajavbot/Enemigo/Golpe en español, MetajavbotDe/Gegner/Treffer en alemán, MetajavbotEn/Enemy/Hit en inglés), pero los tres funcionan igual por dentro.
de:
    Das eigene Paket von MetajavBots mit allem, was du zum Programmieren eines Kampfroboters brauchst. Es steht bereits in der ersten Zeile jeder Werkstatt-Vorlage als „import metajavbots.api.*;“.
    Je nach Spielsprache heißen Basisklasse und Interfaces anders (MetajavbotDe/Gegner/Treffer auf Deutsch, Metajavbot/Enemigo/Golpe auf Spanisch, MetajavbotEn/Enemy/Hit auf Englisch), funktionieren intern aber identisch.
en:
    MetajavBots' own package with everything you need to program a fighting robot. It is already imported on the first line of every Workshop template as “import metajavbots.api.*;”.
    Depending on the game language, the base class and interfaces use localized names (MetajavbotEn/Enemy/Hit in English, Metajavbot/Enemigo/Golpe in Spanish, MetajavbotDe/Gegner/Treffer in German), all backed by the same engine.

--- Metajavbot
nombre.es: Metajavbot
nombre.de: MetajavbotDe
nombre.en: MetajavbotEn
tipo: clase
es: Clase base abstracta de la que hereda tu robot. El motor llama a sus eventos (alEmpezar, cadaTurno, alVerEnemigo, alRecibirGolpe) y tú das órdenes de movimiento, mira, disparo y memoria.
de: Abstrakte Basisklasse, von der dein Roboter erbt. Die Engine ruft ihre Ereignisse auf (beimStart, jedenZug, beiSicht, beiTreffer) und du gibst Befehle für Bewegung, Zielen, Angriff und Gedächtnis.
en: Abstract base class that your robot extends. The engine calls its event hooks (onStart, onTick, onSeeEnemy, onHit) and you issue movement, aiming, attack and memory commands.
miembros.es:
    void cadaTurno() — se ejecuta unas 30 veces por segundo con tu lógica principal
    void alEmpezar() — se ejecuta una vez al inicio de cada ronda
    void alVerEnemigo(Enemigo e) — salta cuando un rival entra en tu cono de radar
    void alRecibirGolpe(Golpe g) — salta cuando te golpean
    void avanzar(double d) / retroceder(double d) — mueve el robot esa distancia
    void girar(double grados) / girarHacia(double angulo) — gira el cuerpo del robot
    void apuntar(double grados) / apuntarHacia(double angulo) — gira la mira y el radar
    void atacar() / usarEspecial() — dispara las armas o activa el ataque especial de la cabeza
    double blindaje() / energia() / x() / y() — consulta tu estado actual en la arena
    Map<String, Object> memoria() — guarda datos entre rondas de la misma pelea
miembros.de:
    void jedenZug() — läuft etwa 30-mal pro Sekunde mit deiner Hauptlogik
    void beimStart() — läuft einmal zu Beginn jeder Runde
    void beiSicht(Gegner g) — wird aufgerufen, wenn ein Gegner im Radarkegel liegt
    void beiTreffer(Treffer t) — wird aufgerufen, wenn du getroffen wirst
    void vorwaerts(double d) / rueckwaerts(double d) — bewegt den Roboter um diese Strecke
    void drehen(double grad) / drehenNach(double winkel) — dreht den Körper des Roboters
    void zielen(double grad) / zielenNach(double winkel) — dreht Visier und Radar
    void angreifen() / spezial() — feuert die Waffen oder aktiviert die Kopffähigkeit
    double panzerung() / energie() / x() / y() — fragt deinen aktuellen Zustand ab
    Map<String, Object> gedaechtnis() — speichert Daten über Runden desselben Kampfes hinweg
miembros.en:
    void onTick() — runs about 30 times per second with your main logic
    void onStart() — runs once at the start of every round
    void onSeeEnemy(Enemy e) — triggered when a rival enters your radar cone
    void onHit(Hit h) — triggered when you take a hit
    void ahead(double d) / back(double d) — moves the robot by that distance
    void turn(double degrees) / turnTo(double angle) — turns the robot body
    void aim(double degrees) / aimTo(double angle) — turns the sight and radar
    void attack() / useSpecial() — fires your weapons or triggers the head special
    double armor() / energy() / x() / y() — reads your current state in the arena
    Map<String, Object> memory() — stores data across rounds of the same fight
ejemplo:
    import metajavbots.api.*;

    public class MiRobot extends Metajavbot {
        @Override
        public void cadaTurno() {
            avanzar(40);
            apuntar(10);
        }

        @Override
        public void alVerEnemigo(Enemigo e) {
            apuntarHacia(e.angulo());
            atacar();
        }
    }

--- Enemigo
nombre.es: Enemigo
nombre.de: Gegner
nombre.en: Enemy
tipo: interfaz
es: Foto instantánea de un robot enemigo detectado por tu radar. Te llega como parámetro en alVerEnemigo(Enemigo e) y en la lista de enemigosVistos().
de: Momentaufnahme eines feindlichen Roboters im Radar. Kommt als Parameter in beiSicht(Gegner g) und in der Liste von gesehen().
en: Snapshot of an enemy robot detected by your radar. Passed into onSeeEnemy(Enemy e) and returned by seenEnemies().
miembros.es:
    double x() / double y() — coordenadas del enemigo en la arena
    double distancia() — distancia desde tu robot hasta él
    double angulo() — ángulo absoluto en grados para apuntar hacia él
    double rumbo() / double velocidad() — dirección y rapidez con la que se mueve
    double blindaje() — blindaje restante (de 0 a 100)
    String nombre() / String modelo() — nombre y modelo del rival
    boolean vuela() — true si vuela (el cuerpo a cuerpo no le alcanza)
miembros.de:
    double x() / double y() — Koordinaten des Gegners in der Arena
    double entfernung() — Abstand von deinem Roboter bis zu ihm
    double winkel() — absoluter Winkel in Grad zum Zielen
    double richtung() / double geschwindigkeit() — Bewegungsrichtung und Tempo
    double panzerung() — restliche Panzerung (0 bis 100)
    String name() / String modell() — Name und Modell des Gegners
    boolean fliegt() — true, wenn er fliegt (Nahkampf trifft nicht)
miembros.en:
    double x() / double y() — enemy coordinates in the arena
    double distance() — distance from your robot to the enemy
    double angle() — absolute angle in degrees to aim at it
    double heading() / double speed() — direction and speed of travel
    double armor() — remaining armor (0 to 100)
    String name() / String model() — rival name and model
    boolean flies() — true if flying (melee attacks cannot reach it)
ejemplo:
    @Override
    public void alVerEnemigo(Enemigo e) {
        if (e.distancia() < 300 && !e.vuela()) {
            apuntarHacia(e.angulo());
            atacar();
        }
    }

--- Golpe
nombre.es: Golpe
nombre.de: Treffer
nombre.en: Hit
tipo: interfaz
es: Información de un impacto recibido (alRecibirGolpe) o asestado al rival (alAcertar): daño, arma, ángulo y pieza alcanzada.
de: Informationen über einen erhaltenen (beiTreffer) oder erzielten Treffer (beiEigenemTreffer): Schaden, Waffe, Winkel und getroffenes Teil.
en: Details about a hit you took (onHit) or landed (onHitEnemy): damage, weapon, angle and part struck.
miembros.es:

    String arma() — tipo de golpe: "laser", "bala", "misil", "cuerpo", "choque" o "pared"

    String pieza() — pieza alcanzada: "cabeza", "izquierda", "derecha" o "piernas"
miembros.de:
    double schaden() — wie viel Panzerung der Treffer gekostet hat
    String waffe() — Trefferart: "laser", "kugel", "rakete", "nahkampf", "zusammenstoss" oder "wand"
    double winkel() — absoluter Winkel, aus dem der Treffer kam
    String teil() — getroffenes Teil: "kopf", "links", "rechts" oder "beine"
miembros.en:
    double damage() — how much armor the hit removed
    String weapon() — hit type: "laser", "bullet", "missile", "melee", "ram" or "wall"
    double angle() — absolute angle the hit came from
    String part() — part struck: "head", "left", "right" or "legs"
ejemplo:
    @Override
    public void alRecibirGolpe(Golpe g) {
        girarHacia(g.angulo() + 90);
        avanzar(90);
    }

--- TopeDeCalculo
tipo: error
es: Error lanzado automáticamente si tu código supera el presupuesto de pasos de cálculo de un turno (por ejemplo, un bucle infinito o demasiado pesado). Al ser un Error y no una Exception, un catch (Exception) no lo oculta.
de: Ein Error, der automatisch ausgelöst wird, wenn dein Code das Budget an Rechenschritten eines Zugs überschreitet (z. B. eine Endlosschleife oder eine zu schwere Schleife). Da es ein Error statt einer Exception ist, schluckt catch (Exception) ihn nicht.
en: Error thrown automatically when your code exceeds a tick's computation step budget (for example, an infinite or overly heavy loop). Because it extends Error rather than Exception, catch (Exception) does not hide it.
miembros.es:
    String getMessage() — explica que se agotó el límite de pasos del turno
miembros.de:
    String getMessage() — erklärt, dass das Rechenlimit des Zugs erschöpft ist
miembros.en:
    String getMessage() — explains that the tick's step limit was exceeded
ejemplo:
    // Evita bucles sin salida en cadaTurno(): el motor lanzará TopeDeCalculo. || Vermeide Endlosschleifen in jedenZug(): Die Engine wirft TopeDeCalculo. || Avoid infinite loops in onTick(): the engine will throw TopeDeCalculo.
    for (int i = 0; i < 10; i++) {
        // trabajo acotado por turno || begrenzte Arbeit pro Zug || bounded work per tick
    }

--- BeforeEach

--- Assertions
tipo: clase
solo_ejercicio: true
es: Colección de métodos estáticos para comprobar que tu código produce el valor, la condición o la excepción esperada.
de: Sammlung statischer Methoden, um erwartete Werte, Bedingungen oder Exceptions zu prüfen.
en: Collection of static methods to verify expected values, conditions or thrown exceptions.
miembros.es:
    assertEquals(esperado, real) — comprueba igualdad (y con delta para double)
    assertNotEquals(noEsperado, real) — comprueba que dos valores son distintos
    assertTrue(cond) / assertFalse(cond) — comprueba una condición booleana
    assertNull(o) / assertNotNull(o) — comprueba si una referencia es null o no
    assertArrayEquals(esp, real) — compara arrays por contenido
    assertThrows(Clase.class, () -> ...) — exige que el bloque lance esa excepción
    assertDoesNotThrow(() -> ...) — exige que no se lance ninguna excepción
    fail(mensaje) — hace fallar la prueba inmediatamente
miembros.de:
    assertEquals(erwartet, ist) — prüft Gleichheit (mit Delta für double)
    assertNotEquals(nichtErwartet, ist) — prüft Ungleichheit
    assertTrue(bed) / assertFalse(bed) — prüft eine boolesche Bedingung
    assertNull(o) / assertNotNull(o) — prüft auf null oder nicht null
    assertArrayEquals(erw, ist) — vergleicht Arrays nach Inhalt
    assertThrows(Typ.class, () -> ...) — verlangt, dass diese Exception fliegt
    assertDoesNotThrow(() -> ...) — verlangt, dass keine Exception fliegt
    fail(nachricht) — lässt den Test sofort fehlschlagen
miembros.en:
    assertEquals(expected, actual) — checks equality (with delta for doubles)
    assertNotEquals(unexpected, actual) — checks inequality
    assertTrue(cond) / assertFalse(cond) — checks a boolean condition
    assertNull(o) / assertNotNull(o) — checks whether a reference is null
    assertArrayEquals(exp, actual) — compares array contents
    assertThrows(Type.class, () -> ...) — asserts that the block throws that exception
    assertDoesNotThrow(() -> ...) — asserts that no exception is thrown
    fail(message) — immediately fails the test
ejemplo:
    import static metajavbots.junit.Assertions.*;

    assertEquals(5.0, Math.hypot(3, 4), 1e-6);
    assertThrows(ArithmeticException.class, () -> { int x = 1 / 0; });

=== paquete java.lang
import: (automático: no necesita import)
auto: true
plantilla: false
solo_ejercicio: false
resumen.es: Clases fundamentales de Java (String, Math, Object, envoltorios, excepciones y anotaciones básicas). Se importa siempre automáticamente.
resumen.de: Grundlegende Java-Klassen (String, Math, Object, Wrapper, Exceptions und Basis-Annotationen). Wird immer automatisch importiert.
resumen.en: Core Java classes (String, Math, Object, wrappers, exceptions and basic annotations). Always imported automatically.

    In MetajavBots erlaubt der Wächter (Vigilante) die Kernklassen für Rechnen, Text, Wrapper, Basis-Interfaces und übliche Exceptions, sperrt aber gefährliche Systemzugriffe und Reflexion.
en:
    The only package Java imports automatically in every file: you can use String, Math, Integer, Double, System or IllegalArgumentException without writing any import line.
    In MetajavBots, the sandbox allows core computation, text, wrapper, basic interface and common exception classes, while blocking unsafe OS access and reflection.
bloqueado.es: Runtime, ProcessBuilder, Process, ClassLoader, System.exit, System.in, System.getenv, System.getProperty, Class.forName y la reflexión. Además, Thread y ThreadLocal solo se permiten en ejercicios (bloqueados en robots).
bloqueado.de: Runtime, ProcessBuilder, Process, ClassLoader, System.exit, System.in, System.getenv, System.getProperty, Class.forName und Reflexion. Thread und ThreadLocal sind zudem nur in Übungen erlaubt (in Robotern gesperrt).
bloqueado.en: Runtime, ProcessBuilder, Process, ClassLoader, System.exit, System.in, System.getenv, System.getProperty, Class.forName and reflection. Thread and ThreadLocal are allowed only in exercises (blocked in robots).
