# La API de los robots (con explicaciones pedagógicas y pseudocódigo por idioma).

=== api.alEmpezar
tema: 11
firma: void alEmpezar()
firma.de: void beimStart()
firma.en: void onStart()
es: Evento sin parámetros ni valor de retorno. El motor lo ejecuta una sola vez al empezar cada ronda, justo antes del turno 0. Úsalo para inicializar variables, colocar el radar o dar la primera orden de movimiento.
de: Ereignis ohne Parameter und Rückgabewert. Wird einmal zu Beginn jeder Runde direkt vor Zug 0 ausgeführt. Ideal für Startwerte, Startbefehle oder das Lesen aus dem Gedächtnis.
en: Event with no parameters or return value. Runs once at the start of every round just before tick 0. Use it to initialize variables, set up aim, or issue the opening move order.
donde.es: Decláralo con @Override en el cuerpo de tu clase Metajavbot, nunca dentro de otro método; no lo llames tú, sustituye al constructor para órdenes iniciales.
donde.de: Mit @Override direkt im Rumpf deiner MetajavbotDe-Klasse deklarieren, nie in einer anderen Methode; nicht selbst aufrufen, ersetzt den Konstruktor für Startbefehle.
donde.en: Declare with @Override directly inside your MetajavbotEn class body, never nested in another method; don't call it manually—use it instead of a constructor for opening orders.
ejemplo.es:
    AL EMPEZAR cada ronda:
        apuntar(45)     // orienta la mira al inicio
        avanzar(120)    // arranca hacia el centro
ejemplo.de:
    BEIM START jeder Runde:
        zielen(45)      // Visier am Anfang ausrichten
        vorwaerts(120)  // Richtung Mitte starten
ejemplo.en:
    ON START of each round:
        aim(45)         // orient sight at start
        ahead(120)      // start moving toward center

=== api.cadaTurno
tema: 11
firma: void cadaTurno()
firma.de: void jedenZug()
firma.en: void onTick()
es: Evento principal del robot, sin parámetros ni retorno. El motor lo ejecuta automáticamente unos 30 veces por segundo, al final de cada turno (después de los avisos y de alVerEnemigo). Aquí va tu lógica continua: patrullar, barrer con el radar o decidir el siguiente movimiento.
de: Hauptmethode des Roboters ohne Parameter und Rückgabewert. Läuft automatisch ca. 30-mal pro Sekunde am Ende jedes Zugs (nach Ereignissen und beiSicht). Hierhin gehört deine laufende Steuerung: patrouillieren und Radar schwenken.
en: Main robot hook with no parameters or return value. Runs automatically about 30 times per second at the end of every tick (after event handlers and onSeeEnemy). Put continuous logic here: patrolling and sweeping the radar.
donde.es: Decláralo con @Override directamente en tu clase Metajavbot (no dentro de otro método ni con bucles infinitos dentro, porque el motor lo llama cada turno).
donde.de: Mit @Override direkt in deiner MetajavbotDe-Klasse deklarieren (nie verschachtelt und ohne Endlosschleife darin, da die Engine sie jeden Zug selbst aufruft).
donde.en: Declare with @Override directly in your MetajavbotEn class (never inside another method and without infinite loops inside, as the engine calls it every tick).
ejemplo.es:
    CADA TURNO:
        SI restanteAvance() == 0:
            avanzar(150)
        apuntar(12)     // gira la mira en cada turno
ejemplo.de:
    JEDEN ZUG:
        WENN restStrecke() == 0:
            vorwaerts(150)
        zielen(12)      // dreht das Visier in jedem Zug
ejemplo.en:
    EVERY TICK:
        IF remainingDistance() == 0:
            ahead(150)
        aim(12)         // sweeps the sight every tick

=== api.alVerEnemigo
tema: 11
firma: void alVerEnemigo(Enemigo e)
firma.de: void beiSicht(Gegner g)
firma.en: void onSeeEnemy(Enemy e)
es: Evento sin valor de retorno. Se ejecuta automáticamente antes de cadaTurno en todo turno en que un rival entra en el cono del radar. Recibe el parámetro e (tipo Enemigo) con una foto instantánea de su posición, distancia, ángulo, rumbo, velocidad y blindaje.
de: Ereignis ohne Rückgabewert. Läuft automatisch vor jedenZug in jedem Zug, in dem ein Gegner im Radarkegel liegt. Bekommt g (Gegner) mit Position, Entfernung, Winkel, Richtung, Geschwindigkeit und Panzerung.
en: Event with no return value. Runs automatically before onTick on every tick an opponent is inside your radar cone. Receives e (Enemy) with a snapshot of its position, distance, angle, heading, speed, and armor.
donde.es: Sobrescríbelo en el cuerpo de tu clase Metajavbot, nunca dentro de cadaTurno(); no lo invoques a mano porque solo el motor te pasa el parámetro Enemigo e.
donde.de: Direkt im Rumpf deiner MetajavbotDe-Klasse überschreiben, nie in jedenZug(); nicht selbst aufrufen, denn nur die Engine liefert das Gegner-Objekt g.
donde.en: Override directly in your MetajavbotEn class body, never inside onTick(); do not invoke it yourself since only the engine supplies the Enemy parameter e.
ejemplo.es:
    AL VER enemigo e:
        apuntarHacia(e.angulo())
        SI e.distancia() <= alcanceDerecha():
            atacarDerecha()
ejemplo.de:
    BEI SICHT von Gegner g:
        zielenNach(g.winkel())
        WENN g.entfernung() <= reichweiteRechts():
            angriffRechts()
ejemplo.en:
    ON SEEING enemy e:
        aimTo(e.angle())
        IF e.distance() <= rangeRight():
            attackRight()

=== api.alRecibirGolpe
tema: 11
firma: void alRecibirGolpe(Golpe g)
firma.de: void beiTreffer(Treffer t)
firma.en: void onHit(Hit h)
es: Evento sin retorno. Se ejecuta al inicio del turno cuando el robot recibió al menos un impacto en el turno anterior. Recibe g (Golpe) indicando el daño sufrido, el arma atacante, el ángulo desde el que vino el golpe y qué pieza recibió el daño.
de: Ereignis ohne Rückgabewert. Läuft zu Beginn des Zugs, wenn du im vorigen Zug getroffen wurdest. Bekommt t (Treffer) mit Schaden, Angriffs-Waffe, Herkunftswinkel und getroffenem Teil.
en: Event with no return value. Runs at the start of the tick when your robot took a hit on the previous tick. Receives h (Hit) telling the damage taken, weapon used, incoming angle, and which body part was hit.
donde.es: Decláralo con @Override a nivel de clase en Metajavbot para reaccionar a impactos; no va dentro de otros métodos ni debes llamarlo manualmente.
donde.de: Mit @Override auf Klassenebene in MetajavbotDe anlegen, um auf Treffer zu reagieren; gehört nicht in andere Methoden und wird nicht von Hand aufgerufen.
donde.en: Declare with @Override at class level in MetajavbotEn to react to incoming hits; never place it inside another method or call it directly.
ejemplo.es:
    AL RECIBIR golpe g:
        girarHacia(g.angulo() + 90)  // colócate de lado al tiro
        avanzar(90)                  // sal de la línea de fuego
ejemplo.de:
    BEI TREFFER t:
        drehenNach(t.winkel() + 90)  // seitlich zur Schusslinie
        vorwaerts(90)                // aus der Schussbahn fahren
ejemplo.en:
    ON HIT h:
        turnTo(h.angle() + 90)       // move perpendicular to shot
        ahead(90)                    // step out of the line of fire

=== api.avanzar
tema: 01
firma: void avanzar(double distancia)
firma.de: void vorwaerts(double strecke)
firma.en: void ahead(double distance)
es: Orden de movimiento no bloqueante, sin retorno. Parámetro: distancia en píxeles (positiva hacia delante, negativa hacia atrás). Guarda la orden para ejecutarse turno a turno y sustituye a la orden de avance pendiente anterior.
de: Nicht-blockierender Fahrbefehl ohne Rückgabewert. Parameter: strecke in Pixeln (positiv vorwärts, negativ rückwärts). Merkt sich die Strecke für die folgenden Züge und ersetzt einen noch laufenden Fahrbefehl.
en: Non-blocking movement order with no return value. Parameter: distance in pixels (positive forward, negative backward). Queues movement over upcoming ticks and replaces any previous pending move order.
donde.es: Llámalo dentro de alEmpezar(), cadaTurno() o un evento, mejor tras comprobar restanteAvance() == 0; nunca en el constructor ni en el cuerpo de la clase.
donde.de: In beimStart(), jedenZug() oder einem Ereignis aufrufen, idealerweise wenn restStrecke() == 0 gilt; nie im Konstruktor oder direkt im Klassenrumpf.
donde.en: Call inside onStart(), onTick(), or an event handler, ideally when remainingDistance() == 0; never in the constructor or directly in the class body.
ejemplo.es:
    // Ordena recorrer 120 px si ya terminó el tramo previo:
    SI restanteAvance() == 0:
        avanzar(120)
ejemplo.de:
    // Fährt 120 Pixel vor, sobald der alte Auftrag fertig ist:
    WENN restStrecke() == 0:
        vorwaerts(120)
ejemplo.en:
    // Move 120 px once previous order completes:
    IF remainingDistance() == 0:
        ahead(120)

=== api.girar
tema: 01
firma: void girar(double grados)
firma.de: void drehen(double grad)
firma.en: void turn(double degrees)
es: Orden de giro del cuerpo no bloqueante, sin retorno. Parámetro: grados relativos a tu rumbo actual (positivo gira a la izquierda/antihorario; negativo a la derecha). Se ejecuta poco a poco en los turnos siguientes según la velocidad de giro.
de: Nicht-blockierender Drehbefehl ohne Rückgabewert. Parameter: grad relativ zur aktuellen Richtung (positiv links/gegen Uhrzeigersinn; negativ rechts). Wird Zug um Zug mit deinem Drehtempo ausgeführt.
en: Non-blocking body rotation order with no return value. Parameter: degrees relative to current heading (positive turns left/CCW; negative turns right). Executed over subsequent ticks at your turn speed.
donde.es: Llámalo dentro de cadaTurno() o eventos de choque para rotar el cuerpo; no lo pongas en el constructor ni lo confundas con apuntar() si solo quieres mover la mira.
donde.de: In jedenZug() oder Kollisionsereignissen aufrufen, um den Rumpf zu drehen; nie im Konstruktor nutzen und nicht mit zielen() verwechseln.
donde.en: Call inside onTick() or collision events to rotate the chassis; never in the constructor, and don't confuse it with aim() when you only want to turn the turret.
ejemplo.es:
    // Gira 90 grados a la izquierda poco a poco:
    SI restanteGiro() == 0:
        girar(90)
ejemplo.de:
    // Dreht schrittweise um 90 Grad nach links:
    WENN restDrehung() == 0:
        drehen(90)
ejemplo.en:
    // Turn 90 degrees left over upcoming ticks:
    IF remainingTurn() == 0:
        turn(90)

=== api.girarHacia
tema: 03
firma: void girarHacia(double angulo)
firma.de: void drehenNach(double winkel)
firma.en: void turnTo(double angle)
es: Orden de giro absoluto sin retorno. Parámetro: angulo destino en grados (0 derecha/este, 90 arriba/norte). Calcula automáticamente la diferencia normalizada desde tu rumbo() para girar por el camino más corto en los siguientes turnos.
de: Absoluter Drehbefehl ohne Rückgabewert. Parameter: Zielwinkel in Grad (0 rechts/Osten, 90 oben/Norden). Berechnet automatisch den kürzesten Weg ab richtung() für die nächsten Züge.
en: Absolute body turn order with no return value. Parameter: target angle in degrees (0 right/east, 90 up/north). Computes the shortest normalized delta from heading() over upcoming ticks.
donde.es: Llámalo dentro de alVerEnemigo(), alRecibirGolpe() o cadaTurno() pasando un ángulo absoluto (como e.angulo() o g.angulo() + 90); nunca en el constructor.
donde.de: In beiSicht(), beiTreffer() oder jedenZug() mit einem absoluten Winkel (z. B. g.winkel() oder t.winkel() + 90) aufrufen; nie im Konstruktor.
donde.en: Call inside onSeeEnemy(), onHit(), or onTick() with an absolute angle (like e.angle() or h.angle() + 90); never in the constructor.
ejemplo.es:
    // Mira hacia el centro de la arena:
    girarHacia(anguloHacia(anchoArena() / 2, altoArena() / 2))
ejemplo.de:
    // Zur Mitte der Arena drehen:
    drehenNach(winkelZu(arenaBreite() / 2, arenaHoehe() / 2))

es: Método de consulta sobre Enemigo. Devuelve true si ese robot está en el aire ahora (alas, propulsor antigravedad, un salto o un volteo).
