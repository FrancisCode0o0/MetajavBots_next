[peonza]
modelo: remolino
titulo: La Peonza | Der Kreisel | The Spinning Top
sintoma: Gira y gira en el sitio y nunca llega a ninguna parte. | Dreht und dreht sich auf der Stelle und kommt nirgendwo an. | It spins and spins on the spot and never gets anywhere.
pista: ¿Cuándo debería girar? Mira qué pasa en cada turno y qué se comprueba antes de avanzar. | Wann sollte er sich drehen? Schau, was in jedem Zug passiert und was vor dem Fahren geprüft wird. | When should it turn? Look at what happens every tick and what is checked before moving.
objetivo: aciertos>=3
rival: chatarra
nivel: 0.12
codigo:
    import metajavbots.api.*;

    public class Peonza extends Metajavbot {

        @Override
        public void cadaTurno() {
            girar(35);
            if (restanteAvance() == 0) {
                avanzar(120);
            }
            apuntar(12);
        }

        @Override
        public void alVerEnemigo(Enemigo e) {
            apuntarHacia(e.angulo());
            atacar();
        }
    }

[timido]
modelo: pixel
titulo: El Tímido | Der Schüchterne | The Shy One
sintoma: Se acerca al enemigo, lo mira fijamente… y nunca ataca. | Fährt an den Gegner heran, starrt ihn an … und greift nie an. | It drives up to the enemy, stares at it… and never attacks.
pista: Lee la condición del «if» en voz alta. ¿Puede una distancia ser menor que cero? | Lies die Bedingung des „if“ laut vor. Kann ein Abstand kleiner als null sein? | Read the “if” condition out loud. Can a distance be less than zero?
objetivo: aciertos>=3
rival: grulla
nivel: 0.15
codigo:
    import metajavbots.api.*;

    public class Timido extends Metajavbot {

        @Override
        public void cadaTurno() {
            if (restanteAvance() == 0) {
                avanzar(90);
                girar(30);
            }
            apuntar(10);
        }

        @Override
        public void alVerEnemigo(Enemigo e) {
            apuntarHacia(e.angulo());
            if (e.distancia() < 0) {
                atacar();
            }
        }
    }

[olvidadizo]
modelo: abaco
titulo: El Olvidadizo | Der Vergessliche | The Forgetful One
sintoma: Tendría que esperar unos turnos y luego atacar con ganas, pero no ataca nunca: cada turno empieza a contar desde cero. | Er sollte ein paar Züge warten und dann kräftig angreifen, greift aber nie an: In jedem Zug fängt er wieder bei null an. | It should wait a few ticks and then attack hard, but it never attacks: every tick it starts counting from zero.
pista: ¿Dónde está declarada la variable que cuenta? ¿Qué le pasa a una variable local cuando el método termina? | Wo ist die Zählvariable deklariert? Was passiert mit einer lokalen Variable, wenn die Methode endet? | Where is the counting variable declared? What happens to a local variable when the method ends?
objetivo: aciertos>=3
rival: tejedora
nivel: 0.15
codigo:
    import metajavbots.api.*;

    public class Olvidadizo extends Metajavbot {

        private boolean listo;

        @Override
        public void cadaTurno() {
            int turnos = 0;
            turnos++;
            listo = turnos > 20;
            if (restanteAvance() == 0) {
                avanzar(100);
                girar(35);
            }
            apuntar(12);
        }

        @Override
        public void alVerEnemigo(Enemigo e) {
            apuntarHacia(e.angulo());
            if (listo) {
                atacar();
            }
        }
    }
