# REFERENCIA rápida de Java para el buscador de la API, ordenada por los 22 temas (res/datos/temas.txt).
# Una entrada por bloque:
#   === id        «sintaxis.…» para lo que es del lenguaje; «Clase.miembro» para la biblioteca estándar
#   tema: NN      el tema en que se aprende
#   firma:        la forma general o la firma del método
#   es: de: en:   qué hace, en una línea por idioma

# Las novedades dicen desde qué versión de Java existen. Los ejemplos usan la API del robot (Metajavbot).

# ==================================================================== 01 Primeros pasos

=== sintaxis.main
tema: 01
firma: public static void main(String[] args) { ... }
es: El punto de entrada de un programa: Java empieza por aquí. Los robots no lo necesitan.
de: Der Einstiegspunkt eines Programms: Hier startet Java. Roboter brauchen ihn nicht.
en: A program's entry point: Java starts here. Robots don't need one.
ejemplo: public static void main(String[] args) { System.out.println("Hola"); }

=== sintaxis.sentencia
tema: 01
firma: sentencia;   { sentencia1; sentencia2; }
es: Cada orden termina en «;». Las llaves agrupan varias sentencias en un bloque.
de: Jeder Befehl endet mit „;“. Geschweifte Klammern fassen mehrere Anweisungen zu einem Block zusammen.
en: Every command ends with ";". Curly braces group several statements into a block.
ejemplo: { girar(10); avanzar(50); }

=== sintaxis.comentario
tema: 01
firma: // una línea      /* varias líneas */      /** Javadoc */
es: Texto para personas que Java ignora. Explica el porqué, no lo evidente.
de: Text für Menschen, den Java ignoriert. Erkläre das Warum, nicht das Offensichtliche.
en: Text for people that Java ignores. Explain the why, not the obvious.
ejemplo: avanzar(50);  // me alejo de la pared

=== System.out.println
tema: 01
firma: void println(Object x)
es: Escribe el valor en la consola y salta de línea. En el robot también vale escribir(...).
de: Schreibt den Wert in die Konsole und beginnt eine neue Zeile. Im Roboter geht auch ausgeben(...).
en: Prints the value to the console and ends the line. In a robot you can also use print(...).
ejemplo: System.out.println("Blindaje: " + blindaje());

=== System.out.print
tema: 01
firma: void print(Object x)
es: Como println, pero sin saltar de línea.
de: Wie println, aber ohne Zeilenumbruch.
en: Like println, but without a line break.
ejemplo: System.out.print("a"); System.out.print("b");  // ab

=== System.out.printf
tema: 01
firma: PrintStream printf(String formato, Object... args)
es: Escribe con formato: %d entero, %.2f decimal con 2 cifras, %s texto, %n salto de línea.
de: Formatierte Ausgabe: %d Ganzzahl, %.2f Kommazahl mit 2 Stellen, %s Text, %n Zeilenumbruch.
en: Formatted output: %d integer, %.2f decimal with 2 digits, %s text, %n line break.
ejemplo: System.out.printf("x=%.1f y=%.1f%n", x(), y());

=== sintaxis.escape
tema: 01
firma: \n   \t   \"   \'   \\
es: Caracteres especiales dentro de un texto: salto de línea, tabulador, comillas y barra invertida.
de: Sonderzeichen in einem Text: Zeilenumbruch, Tabulator, Anführungszeichen und Backslash.
en: Special characters inside a string: new line, tab, quotes and backslash.
ejemplo: System.out.println("Dijo \"¡fuego!\"\ny disparó");

# ==================================================================== 02 Variables y tipos primitivos

=== sintaxis.variable
tema: 02
firma: tipo nombre = valor;
es: Una caja con nombre que guarda un valor. Se declara una vez y luego se puede cambiar.
de: Eine benannte Kiste, die einen Wert speichert. Einmal deklariert, später änderbar.
en: A named box that holds a value. Declared once, it can be changed later.
ejemplo: int vueltas = 0; vueltas = vueltas + 1;

=== sintaxis.tipos.primitivos
tema: 02
firma: byte  short  int  long  float  double  char  boolean
es: Los 8 tipos básicos. Los más usados: int (enteros), double (decimales), boolean (true/false), char ('a').
de: Die 8 Grundtypen. Am häufigsten: int (Ganzzahlen), double (Kommazahlen), boolean (true/false), char ('a').
en: The 8 basic types. Most used: int (whole numbers), double (decimals), boolean (true/false), char ('a').
ejemplo: int n = 3; double d = 2.5; boolean listo = true; char c = 'x';

=== sintaxis.literales
tema: 02
firma: 42   3.14   1e3   10L   2.5f   'a'   "texto"   true   0xFF   0b101   1_000_000
es: Formas de escribir valores en el código. Los guiones bajos separan cifras para leerlas mejor.
de: Schreibweisen für Werte im Code. Unterstriche trennen Ziffern, damit man sie besser liest.
en: Ways to write values in code. Underscores separate digits to make them easier to read.
ejemplo: long distancia = 1_000_000L; int mascara = 0b1010;  // 10

=== sintaxis.var
tema: 02
firma: var nombre = valor;
es: Java deduce el tipo por el valor. Solo en variables locales con valor inicial. Desde Java 10.
de: Java leitet den Typ aus dem Wert ab. Nur für lokale Variablen mit Startwert. Seit Java 10.
en: Java infers the type from the value. Only for local variables with an initial value. Since Java 10.
ejemplo: var enemigos = enemigosVistos();  // List<Enemigo>

=== sintaxis.final
tema: 02
firma: final tipo nombre = valor;      static final tipo CONSTANTE = valor;
es: Una variable que no se puede reasignar. Las constantes de clase van en MAYÚSCULAS con static final.
de: Eine Variable, die nicht neu zugewiesen werden kann. Klassenkonstanten: static final, in GROSSBUCHSTABEN.
en: A variable that can't be reassigned. Class constants use static final and UPPER_CASE names.
ejemplo: static final double DISTANCIA_SEGURA = 150;

=== sintaxis.cast
tema: 02
firma: (tipo) expresion
es: Convierte un valor a otro tipo. De double a int corta los decimales (no redondea).
de: Wandelt einen Wert in einen anderen Typ um. Von double nach int werden Nachkommastellen abgeschnitten.
en: Converts a value to another type. From double to int the decimals are cut off (not rounded).
ejemplo: int pasos = (int) 7.9;  // 7

=== Integer.MAX_VALUE
tema: 02
firma: static final int MAX_VALUE   // 2147483647   (y MIN_VALUE: -2147483648)
es: El int más grande. Si te pasas, da la vuelta a negativo (desbordamiento). Para más, usa long.
de: Der größte int. Gehst du darüber, springt er ins Negative (Überlauf). Für mehr nimm long.
en: The largest int. Go past it and it wraps around to negative (overflow). For more, use long.
ejemplo: int x = Integer.MAX_VALUE + 1;  // -2147483648

# ==================================================================== 03 Operadores y expresiones

=== sintaxis.aritmetica
tema: 03
firma: a + b   a - b   a * b   a / b   a % b
es: Suma, resta, multiplicación, división y resto. Entre dos int, «/» descarta los decimales.
de: Addition, Subtraktion, Multiplikation, Division und Rest. Zwischen zwei int verwirft „/“ die Nachkommastellen.
en: Addition, subtraction, multiplication, division and remainder. Between two ints, "/" drops the decimals.
ejemplo: 7 / 2  // 3      7 / 2.0  // 3.5      7 % 2  // 1

=== sintaxis.incremento
tema: 03
firma: x++   x--   ++x   --x   x += n   x -= n   x *= n   x /= n
es: Atajos para cambiar una variable: x++ suma 1, x += 5 suma 5.
de: Abkürzungen zum Ändern einer Variable: x++ addiert 1, x += 5 addiert 5.
en: Shortcuts to change a variable: x++ adds 1, x += 5 adds 5.
ejemplo: int turnos = 0; turnos++; turnos += 10;  // 11

=== sintaxis.comparacion
tema: 03
firma: a == b   a != b   a < b   a <= b   a > b   a >= b
es: Comparan dos valores y dan un boolean. Para textos y objetos usa equals, no ==.
de: Vergleichen zwei Werte und liefern einen boolean. Für Texte und Objekte nimm equals, nicht ==.
en: Compare two values and give a boolean. For strings and objects use equals, not ==.
ejemplo: boolean cerca = e.distancia() < 100;

=== sintaxis.logicos
tema: 03
firma: a && b   a || b   !a
es: Y, O y NO. && y || no miran la parte derecha si ya saben el resultado (cortocircuito).
de: UND, ODER und NICHT. && und || werten rechts nicht aus, wenn das Ergebnis schon feststeht (Kurzschluss).
en: AND, OR and NOT. && and || skip the right side when the result is already known (short-circuit).
ejemplo: if (listoDerecha() && energia() > 10) atacarDerecha();

=== sintaxis.ternario
tema: 03
firma: condicion ? valorSiTrue : valorSiFalse
es: Un if en forma de expresión: elige entre dos valores.
de: Ein if als Ausdruck: wählt zwischen zwei Werten.
en: An if as an expression: picks one of two values.
ejemplo: double paso = blindaje() < 30 ? -50 : 50;

=== sintaxis.precedencia
tema: 03
firma: ()   !  ++  --   * / %   + -   < > <= >=   == !=   &&   ||   ?:   = +=
es: El orden en que se calculan los operadores, de primero a último. En caso de duda, paréntesis.
de: Die Reihenfolge, in der Operatoren ausgewertet werden, von zuerst bis zuletzt. Im Zweifel Klammern.
en: The order in which operators are evaluated, first to last. When in doubt, use brackets.
ejemplo: 2 + 3 * 4  // 14      (2 + 3) * 4  // 20

=== Math.abs
tema: 03
firma: static double abs(double a)   // también int y long
es: El valor absoluto: el número sin signo.
de: Der Betrag: die Zahl ohne Vorzeichen.
en: The absolute value: the number without its sign.
ejemplo: Math.abs(-15.5)  // 15.5

=== Math.max
tema: 03
firma: static double max(double a, double b)   // también int y long
es: El mayor de dos números.
de: Die größere von zwei Zahlen.
en: The larger of two numbers.
ejemplo: Math.max(3, 8)  // 8

=== Math.min
tema: 03
firma: static double min(double a, double b)   // también int y long
es: El menor de dos números.
de: Die kleinere von zwei Zahlen.
en: The smaller of two numbers.
ejemplo: double paso = Math.min(restanteAvance(), 20);

=== Math.pow
tema: 03
firma: static double pow(double base, double exponente)
es: La potencia: base elevada al exponente. Para un cuadrado, x * x es más rápido.
de: Die Potenz: Basis hoch Exponent. Für ein Quadrat ist x * x schneller.
en: The power: base raised to the exponent. For a square, x * x is faster.
ejemplo: Math.pow(2, 10)  // 1024.0

=== Math.sqrt
tema: 03
firma: static double sqrt(double a)
es: La raíz cuadrada.
de: Die Quadratwurzel.
en: The square root.
ejemplo: Math.sqrt(dx * dx + dy * dy)

=== Math.round
tema: 03
firma: static long round(double a)
es: Redondea al entero más cercano (0,5 hacia arriba). Devuelve long: haz cast a int si lo necesitas.
de: Rundet zur nächsten Ganzzahl (0,5 nach oben). Liefert long: Bei Bedarf nach int casten.
en: Rounds to the nearest whole number (0.5 goes up). Returns long: cast to int if you need one.
ejemplo: int r = (int) Math.round(2.5);  // 3

=== Math.floor
tema: 03
firma: static double floor(double a)      static double ceil(double a)
es: floor redondea hacia abajo y ceil hacia arriba. Ambos devuelven double.
de: floor rundet ab, ceil rundet auf. Beide liefern double.
en: floor rounds down and ceil rounds up. Both return a double.
ejemplo: Math.floor(2.7)  // 2.0      Math.ceil(2.1)  // 3.0

=== Math.random
tema: 03
firma: static double random()
es: Un decimal al azar en [0, 1). En el robot mejor azar(): la misma pelea repetida da lo mismo.
de: Eine Zufallszahl in [0, 1). Im Roboter lieber zufall(): Derselbe Kampf ergibt dasselbe.
en: A random decimal in [0, 1). In a robot prefer random(): replaying the same fight gives the same result.
ejemplo: int dado = (int) (Math.random() * 6) + 1;  // 1..6

=== Math.sin
tema: 03
firma: static double sin(double radianes)      static double cos(double radianes)      Math.PI
es: Seno y coseno de un ángulo en radianes. Pasa los grados del robot con Math.toRadians.
de: Sinus und Kosinus eines Winkels im Bogenmaß. Rechne die Grad des Roboters mit Math.toRadians um.
en: Sine and cosine of an angle in radians. Convert the robot's degrees with Math.toRadians.
ejemplo: double dx = Math.cos(Math.toRadians(rumbo())) * 50;

=== Math.toRadians
tema: 03
firma: static double toRadians(double grados)      static double toDegrees(double radianes)
es: Pasa de grados a radianes; toDegrees hace lo contrario. 180 grados son Math.PI radianes.
de: Rechnet Grad in Bogenmaß um; toDegrees macht das Gegenteil. 180 Grad sind Math.PI.
en: Converts degrees to radians; toDegrees does the opposite. 180 degrees are Math.PI radians.
ejemplo: Math.toDegrees(Math.PI / 2)  // 90.0

=== Math.atan2
tema: 03
firma: static double atan2(double y, double x)
es: El ángulo (en radianes) del punto (x, y) visto desde el origen. Ojo: primero y, después x.
de: Der Winkel (im Bogenmaß) des Punkts (x, y) vom Ursprung aus. Achtung: erst y, dann x.
en: The angle (in radians) of the point (x, y) seen from the origin. Careful: y first, then x.
ejemplo: double grados = Math.toDegrees(Math.atan2(e.y() - y(), e.x() - x()));

=== Math.hypot
tema: 03
firma: static double hypot(double x, double y)
es: La distancia raíz(x² + y²), sin desbordarse con números grandes.
de: Der Abstand Wurzel(x² + y²), ohne Überlauf bei großen Zahlen.
en: The distance sqrt(x² + y²), without overflowing on big numbers.
ejemplo: Math.hypot(3, 4)  // 5.0

=== Math.clamp
tema: 03
firma: static double clamp(double valor, double min, double max)
es: Encierra el valor entre min y max. Desde Java 21.
de: Begrenzt den Wert auf den Bereich von min bis max. Seit Java 21.
en: Clamps the value between min and max. Since Java 21.
ejemplo: Math.clamp(130.0, 0.0, 100.0)  // 100.0

# ==================================================================== 04 Condicionales

=== sintaxis.if
tema: 04
firma: if (condicion) { ... } else { ... }
es: Ejecuta un bloque solo si la condición es true; el else, si es false. El else es opcional.
de: Führt einen Block nur aus, wenn die Bedingung true ist; den else-Block, wenn sie false ist. else ist optional.
en: Runs a block only if the condition is true; the else block if it's false. The else is optional.
ejemplo: if (blindaje() < 30) { retroceder(80); } else { avanzar(40); }

=== sintaxis.else.if
tema: 04
firma: if (c1) { ... } else if (c2) { ... } else { ... }
es: Encadena varias condiciones: se ejecuta solo la primera que se cumpla.
de: Verkettet mehrere Bedingungen: Nur die erste zutreffende wird ausgeführt.
en: Chains several conditions: only the first one that holds runs.
ejemplo: if (d < 100) atacar(); else if (d < 300) avanzar(50); else girar(20);

=== sintaxis.switch
tema: 04
firma: switch (valor) { case A: ...; break; default: ...; }
es: Elige un camino según el valor (int, char, String o enum). Sin break, sigue con el case siguiente.
de: Wählt einen Weg nach dem Wert (int, char, String oder enum). Ohne break geht es beim nächsten case weiter.
en: Picks a path by value (int, char, String or enum). Without break it falls through to the next case.
ejemplo: switch (ronda()) { case 1: decir("¡Hola!"); break; default: decir("Otra vez"); }

=== sintaxis.switch.flecha
tema: 04
firma: switch (valor) { case A, B -> ...; default -> ...; }
es: Switch moderno: sin break ni caídas, varios valores por case, y puede dar un valor. Desde Java 14.
de: Modernes switch: kein break, kein Durchfallen, mehrere Werte pro case, kann einen Wert liefern. Seit Java 14.
en: Modern switch: no break, no fall-through, several values per case, and it can yield a value. Since Java 14.
ejemplo: String plan = switch (ronda()) { case 1, 2 -> "tantear"; default -> "atacar"; };

=== sintaxis.yield
tema: 04
firma: case X -> { ...; yield valor; }
es: Da el valor de un switch-expresión desde un bloque con llaves. Desde Java 14.
de: Liefert den Wert eines switch-Ausdrucks aus einem Block mit Klammern. Seit Java 14.
en: Gives the value of a switch expression from a braced block. Since Java 14.
ejemplo: int v = switch (n) { case 0 -> 0; default -> { int t = n * 2; yield t + 1; } };

# ==================================================================== 05 Bucles

=== sintaxis.while
tema: 05
firma: while (condicion) { ... }
es: Repite el bloque mientras la condición sea true. Si al principio es false, no se ejecuta nunca.
de: Wiederholt den Block, solange die Bedingung true ist. Ist sie anfangs false, läuft er nie.
en: Repeats the block while the condition is true. If it's false at the start, it never runs.
ejemplo: int n = 10; while (n > 0) { n -= 3; }  // n = -2

=== sintaxis.do.while
tema: 05
firma: do { ... } while (condicion);
es: Como while, pero comprueba al final: se ejecuta al menos una vez. Lleva «;» al final.
de: Wie while, prüft aber am Ende: läuft mindestens einmal. Endet mit „;“.
en: Like while, but checks at the end: it runs at least once. Ends with ";".
ejemplo: int n; do { n = azar().nextInt(10); } while (n == 0);

=== sintaxis.for
tema: 05
firma: for (inicio; condicion; paso) { ... }
es: El bucle con contador: empieza, comprueba y avanza en una sola línea.
de: Die Zählschleife: Start, Prüfung und Schritt in einer Zeile.
en: The counting loop: start, check and step in a single line.
ejemplo: for (int i = 0; i < 4; i++) { System.out.println(i); }  // 0 1 2 3

=== sintaxis.break
tema: 05
firma: break;
es: Sale al instante del bucle o del switch en el que está.
de: Verlässt sofort die Schleife oder das switch, in dem es steht.
en: Leaves the loop or switch it's in immediately.
ejemplo: for (Enemigo e : enemigosVistos()) { if (e.distancia() < 50) { atacar(); break; } }

=== sintaxis.continue
tema: 05
firma: continue;
es: Salta el resto de esta vuelta y pasa a la siguiente.
de: Überspringt den Rest dieser Runde und macht mit der nächsten weiter.
en: Skips the rest of this round and moves on to the next.
ejemplo: for (int i = 0; i < 6; i++) { if (i % 2 == 0) continue; System.out.print(i); }  // 135

=== sintaxis.etiqueta
tema: 05
firma: nombre: for (...) { ... break nombre; ... continue nombre; }
es: Un nombre para un bucle: break o continue con ese nombre actúan sobre el bucle exterior.
de: Ein Name für eine Schleife: break oder continue mit diesem Namen wirken auf die äußere Schleife.
en: A name for a loop: break or continue with that name act on the outer loop.
ejemplo: fuera: for (int[] fila : m) for (int v : fila) if (v < 0) break fuera;

# ==================================================================== 06 Métodos

=== sintaxis.metodo
tema: 06
firma: modificadores tipoRetorno nombre(tipo param, ...) { ... }
es: Un bloque de código con nombre que recibe parámetros y puede devolver un valor.
de: Ein benannter Codeblock, der Parameter bekommt und einen Wert zurückgeben kann.
en: A named block of code that takes parameters and can return a value.
ejemplo: double mitad(double d) { return d / 2; }

=== sintaxis.return
tema: 06
firma: return valor;      return;
es: Termina el método. Si el método no es void, devuelve el valor indicado.
de: Beendet die Methode. Ist sie nicht void, gibt sie den angegebenen Wert zurück.
en: Ends the method. If the method isn't void, it returns the given value.
ejemplo: boolean peligro() { return blindaje() < 25; }

=== sintaxis.void
tema: 06
firma: void nombre(...) { ... }
es: El método no devuelve nada: solo hace algo.
de: Die Methode gibt nichts zurück: Sie tut nur etwas.
en: The method returns nothing: it just does something.
ejemplo: void huir() { girar(180); avanzar(100); }

=== sintaxis.sobrecarga
tema: 06
firma: tipo nombre(int a)      tipo nombre(double a)      tipo nombre(int a, int b)
es: Varios métodos con el mismo nombre y distintos parámetros. Java elige según los argumentos.
de: Mehrere Methoden mit gleichem Namen und verschiedenen Parametern. Java wählt nach den Argumenten.
en: Several methods with the same name and different parameters. Java picks by the arguments.
ejemplo: int doble(int x) { return 2 * x; }   String doble(String s) { return s + s; }

=== sintaxis.static
tema: 06
firma: static tipo nombre ...
es: Pertenece a la clase y no a cada objeto. Se usa como Clase.nombre, sin crear objetos.
de: Gehört zur Klasse, nicht zu jedem Objekt. Aufruf als Klasse.name, ohne ein Objekt zu erzeugen.
en: Belongs to the class, not to each object. Used as Class.name, without creating objects.
ejemplo: static int cuadrado(int x) { return x * x; }   // Util.cuadrado(4) = 16

=== sintaxis.varargs
tema: 06
firma: tipo nombre(tipo... valores)
es: Acepta cualquier número de argumentos, que llegan como un array. Va el último. Desde Java 5.
de: Nimmt beliebig viele Argumente, die als Array ankommen. Muss zuletzt stehen. Seit Java 5.
en: Takes any number of arguments, which arrive as an array. Must come last. Since Java 5.
ejemplo: int suma(int... n) { int s = 0; for (int x : n) s += x; return s; }   // suma(1, 2, 3) = 6

=== sintaxis.paso.por.valor
tema: 06
firma: metodo(valor)   // se copia el valor (o la referencia al objeto)
es: Java copia los argumentos: cambiar un parámetro no cambia la variable de fuera; el objeto apuntado, sí.
de: Java kopiert die Argumente: Ein geänderter Parameter ändert die äußere Variable nicht, das Objekt schon.
en: Java copies arguments: changing a parameter doesn't change the outside variable; the object it points to, yes.
ejemplo: void f(int x) { x = 9; }   int a = 1; f(a);  // a sigue valiendo 1

# ==================================================================== 07 Arrays

=== sintaxis.array
tema: 07
firma: tipo[] nombre = new tipo[tamaño];
es: Una fila de valores del mismo tipo con tamaño fijo. Las posiciones van de 0 a length - 1.
de: Eine Reihe von Werten gleichen Typs mit fester Größe. Die Positionen gehen von 0 bis length - 1.
en: A row of values of the same type with a fixed size. Positions go from 0 to length - 1.
ejemplo: double[] distancias = new double[5]; distancias[0] = 120.5;

=== sintaxis.array.literal
tema: 07
firma: tipo[] nombre = { v1, v2, v3 };      new tipo[] { v1, v2 }
es: Crea el array y lo rellena a la vez.
de: Erzeugt das Array und füllt es gleichzeitig.
en: Creates the array and fills it at once.
ejemplo: int[] danos = { 10, 25, 40 };

=== sintaxis.array.length
tema: 07
firma: array.length
es: Cuántas posiciones tiene el array. Es un campo, sin paréntesis (en String es length()).
de: Wie viele Positionen das Array hat. Ein Feld, ohne Klammern (bei String ist es length()).
en: How many positions the array has. It's a field, without brackets (on a String it's length()).
ejemplo: for (int i = 0; i < a.length; i++) suma += a[i];

=== sintaxis.array.2d
tema: 07
firma: tipo[][] m = new tipo[filas][columnas];
es: Un array de arrays: una tabla. Se accede con m[fila][columna].
de: Ein Array aus Arrays: eine Tabelle. Zugriff mit m[zeile][spalte].
en: An array of arrays: a table. Access it with m[row][column].
ejemplo: int[][] mapa = new int[3][4]; mapa[1][2] = 7;

=== sintaxis.for.each
tema: 07

=== JUnit.Test
tema: 22
firma: @Test void nombreDeLaPrueba() { ... }
es: Marca un método como prueba de JUnit 5. Cada prueba comprueba un comportamiento concreto.
de: Markiert eine Methode als JUnit-5-Test. Jeder Test prüft ein bestimmtes Verhalten.
en: Marks a method as a JUnit 5 test. Each test checks one specific behaviour.
ejemplo: @Test void sumaDosNumeros() { assertEquals(5, suma(2, 3)); }

=== Assertions.assertEquals
tema: 22
firma: static void assertEquals(esperado, real)      assertEquals(double e, double r, double margen)
es: Falla si los dos valores no son iguales. Con decimales, da un margen de error.
de: Schlägt fehl, wenn die Werte nicht gleich sind. Bei Kommazahlen eine Toleranz angeben.
en: Fails if the two values aren't equal. With decimals, give a tolerance.
ejemplo: assertEquals(0.5, mitad(1.0), 1e-9);

=== Assertions.assertTrue
tema: 22
firma: static void assertTrue(boolean c)      assertFalse(boolean c)      assertNull(Object o)
es: Falla si la condición no es true (o false, o null).
de: Schlägt fehl, wenn die Bedingung nicht true (oder false, oder null) ist.
en: Fails if the condition isn't true (or false, or null).
ejemplo: assertTrue(lista.isEmpty());

=== Assertions.assertThrows
tema: 22
firma: static <T extends Throwable> T assertThrows(Class<T> tipo, Executable codigo)
es: Falla si el código NO lanza esa excepción. Devuelve la excepción para mirar su mensaje.
de: Schlägt fehl, wenn der Code diese Ausnahme NICHT wirft. Liefert sie zurück, um die Meldung zu prüfen.
en: Fails if the code does NOT throw that exception. Returns it so you can inspect the message.
ejemplo: assertThrows(IllegalArgumentException.class, () -> new Vida(-1));

=== JUnit.BeforeEach
tema: 22
firma: @BeforeEach void preparar() { ... }      @AfterEach      @DisplayName("…")
es: Se ejecuta antes de cada prueba, para empezar siempre desde el mismo estado.
de: Läuft vor jedem Test, damit jeder vom gleichen Zustand startet.
en: Runs before each test, so every test starts from the same state.
ejemplo: @BeforeEach void preparar() { lista = new ArrayList<>(); }

=== sintaxis.assert

en: Checks something that should always be true. Only active when Java runs with -ea.

=== sintaxis.composicion
tema: 22
firma: class A { private final B ayudante; }   // «tiene un» en vez de «es un»
