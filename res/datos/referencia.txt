# REFERENCIA rápida de Java para el buscador de la API, ordenada por los 22 temas (res/datos/temas.txt).
# Una entrada por bloque:
#   === id        «sintaxis.…» para lo que es del lenguaje; «Clase.miembro» para la biblioteca estándar
#   tema: NN      el tema en que se aprende
#   firma:        la forma general o la firma del método
#   es: de: en:   qué hace, en una línea por idioma
#   ejemplo:      una línea de código; «// …» muestra el resultado
# Las novedades dicen desde qué versión de Java existen. Los ejemplos usan la API del robot (Metajavbot).

# ==================================================================== 01 Primeros pasos

=== sintaxis.main
tema: 01
firma: public static void main(String[] args) { ... }
es: El punto de entrada de un programa: Java empieza por aquí. Los robots no lo necesitan.
de: Der Einstiegspunkt eines Programms: Hier startet Java. Roboter brauchen ihn nicht.
en: A program's entry point: Java starts here. Robots don't need one.
donde.es: Decláralo directamente en el cuerpo de una clase Java independiente; en tus robots (Metajavbot) NO lo pongas, porque el motor ejecuta sus eventos.
donde.de: Direkt im Rumpf einer eigenständigen Java-Klasse deklarieren; in Robotern (MetajavbotDe) NICHT verwenden, da die Engine die Ereignisse startet.
donde.en: Declare directly inside a standalone Java class body; do NOT add it to robots (MetajavbotEn), because the engine runs their event methods instead.
ejemplo: public static void main(String[] args) { System.out.println("Hola"); }

=== sintaxis.sentencia
tema: 01
firma: sentencia;   { sentencia1; sentencia2; }
es: Cada orden termina en «;». Las llaves agrupan varias sentencias en un bloque.
de: Jeder Befehl endet mit „;“. Geschweifte Klammern fassen mehrere Anweisungen zu einem Block zusammen.
en: Every command ends with “;”. Curly braces group several statements into a block.
donde.es: Escribe sentencias terminadas en «;» dentro de métodos, constructores o bloques { }; nunca sueltas en el cuerpo de la clase (salvo declaraciones de campos).
donde.de: Anweisungen mit „;“ gehören in Methoden, Konstruktoren oder { }-Blöcke; niemals lose in den Klassenrumpf (außer Felddeklarationen).
donde.en: Write semicolon-terminated statements inside methods, constructors, or { } blocks; never loose in the class body (except field declarations).
ejemplo: { girar(10); avanzar(50); }

=== sintaxis.comentario
tema: 01
firma: // una línea      /* varias líneas */      /** Javadoc */
es: Texto para personas que Java ignora. Explica el porqué, no lo evidente.
de: Text für Menschen, den Java ignoriert. Erkläre das Warum, nicht das Offensichtliche.
en: Text for people that Java ignores. Explain the why, not the obvious.
donde.es: Puedes colocarlo en casi cualquier sitio del archivo; coloca /** Javadoc */ justo encima de una clase o método, y evita meter /* ... */ dentro de otro /* ... */.
donde.de: Kann fast überall stehen; /** Javadoc */ gehört direkt über Klassen oder Methoden, und /* ... */ darf nicht ineinander verschachtelt werden.
donde.en: Can go almost anywhere in a file; place /** Javadoc */ right above a class or method, and never nest /* ... */ inside another /* ... */.
ejemplo: avanzar(50);  // me alejo de la pared

=== System.out.println
tema: 01
firma: void println(Object x)
es: Escribe el valor en la consola y salta de línea. En el robot también vale escribir(...).
de: Schreibt den Wert in die Konsole und beginnt eine neue Zeile. Im Roboter geht auch ausgeben(...).
en: Prints the value to the console and ends the line. In a robot you can also use print(...).
donde.es: Llámalo dentro de métodos o ejercicios de consola para depurar; en robots úsalo con medida en eventos y no sin filtro cada turno (o usa escribir()).
donde.de: In Methoden oder Konsolenübungen zur Ausgabe aufrufen; in Robotern sparsam in Ereignissen nutzen (oder ausgeben()), nicht ungefiltert jeden Zug.
donde.en: Call inside methods or console exercises to print output; in robots use it sparingly in events (or print()), not unconditionally every tick.
ejemplo: System.out.println("Blindaje: " + blindaje());

=== System.out.print
tema: 01
firma: void print(Object x)
es: Como println, pero sin saltar de línea.
de: Wie println, aber ohne Zeilenumbruch.
en: Like println, but without a line break.
donde.es: Úsalo dentro de bucles o métodos cuando quieras construir una misma línea en varios pasos; no va en el cuerpo de la clase fuera de un método.
donde.de: In Schleifen oder Methoden nutzen, wenn mehrere Ausgaben in derselben Zeile erscheinen sollen; nicht außerhalb einer Methode im Klassenrumpf.
donde.en: Use inside loops or methods when building a single line across several calls; never place it directly in the class body.
ejemplo: System.out.print("a"); System.out.print("b");  // ab

en: Formatted output: %d integer, %.2f decimal with 2 digits, %s text, %n line break.
donde.es: Llámalo dentro de métodos cuando necesites alinear tablas o limitar decimales (%.1f); asegúrate de poner tantos argumentos como huecos % haya.
donde.de: In Methoden aufrufen, um Zahlen mit fester Stellenzahl (%.1f) oder Tabellen auszugeben; Anzahl und Typ der Argumente müssen zu den %-Platzhaltern passen.
donde.en: Call inside methods when formatting decimals (%.1f) or aligned output; match the count and types of arguments to the % placeholders.
ejemplo: System.out.printf("x=%.1f y=%.1f%n", x(), y());

en: Special characters inside a string: new line, tab, quotes and backslash.

donde.en: Place only inside String ("...") or char ('...') literals; outside quotes they cause a compile error.
ejemplo: System.out.println("Dijo \"¡fuego!\"\ny disparó");

# ==================================================================== 02 Variables y tipos primitivos

=== sintaxis.variable
tema: 02
firma: tipo nombre = valor;
es: Una caja con nombre que guarda un valor. Se declara una vez y luego se puede cambiar.
de: Eine benannte Kiste, die einen Wert speichert. Einmal deklariert, später änderbar.
en: A named box that holds a value. Declared once, it can be changed later.
donde.es: Declárala dentro de un método si solo sirve ahí, o en el cuerpo de la clase si debe recordar su valor entre turnos; nunca dentro de otra expresión.
donde.de: In einer Methode deklarieren, wenn sie nur lokal gilt, oder im Klassenrumpf für Werte über mehrere Züge; nicht mitten in einem Ausdruck.
donde.en: Declare inside a method for temporary values, or in the class body to keep state across ticks; never inside another expression.
ejemplo: int vueltas = 0; vueltas = vueltas + 1;

=== sintaxis.tipos.primitivos
tema: 02
firma: byte  short  int  long  float  double  char  boolean
es: Los 8 tipos básicos. Los más usados: int (enteros), double (decimales), boolean (true/false), char ('a').
de: Die 8 Grundtypen. Am häufigsten: int (Ganzzahlen), double (Kommazahlen), boolean (true/false), char ('a').
en: The 8 basic types. Most used: int (whole numbers), double (decimals), boolean (true/false), char ('a').
donde.es: Úsalos al declarar variables, campos, parámetros o retornos de métodos; NO pueden ponerse como tipo genérico dentro de <...> (usa Integer, Double, etc.).
donde.de: Für Variablen, Felder, Parameter und Rückgabewerte einsetzen; NICHT als Typparameter in <...> verwendbar (dort Integer, Double usw. nutzen).
donde.en: Use for variables, fields, parameters, and return types; they CANNOT go inside generic <...> brackets (use Integer, Double, etc. instead).
ejemplo: int n = 3; double d = 2.5; boolean listo = true; char c = 'x';

=== sintaxis.literales
tema: 02
firma: 42   3.14   1e3   10L   2.5f   'a'   "texto"   true   0xFF   0b101   1_000_000
es: Formas de escribir valores en el código. Los guiones bajos separan cifras para leerlas mejor.
de: Schreibweisen für Werte im Code. Unterstriche trennen Ziffern, damit man sie besser liest.
en: Ways to write values in code. Underscores separate digits to make them easier to read.
donde.es: Colócalos en expresiones, inicializaciones o argumentos de métodos; los guiones bajos solo van entre dígitos, nunca al principio, al final ni junto al punto decimal.
donde.de: In Ausdrücken, Zuweisungen oder Methodenargumenten nutzen; Unterstriche dürfen nur zwischen Ziffern stehen, nie am Rand oder direkt am Dezimalpunkt.
donde.en: Use in expressions, assignments, or method arguments; underscores go only between digits, never at the start, end, or next to a decimal point.
ejemplo: long distancia = 1_000_000L; int mascara = 0b1010;  // 10

=== sintaxis.var
tema: 02
firma: var nombre = valor;
es: Java deduce el tipo por el valor. Solo en variables locales con valor inicial. Desde Java 10.
de: Java leitet den Typ aus dem Wert ab. Nur für lokale Variablen mit Startwert. Seit Java 10.
en: Java infers the type from the value. Only for local variables with an initial value. Since Java 10.
donde.es: Úsalo solo en variables locales dentro de métodos o bucles con valor inicial; NO vale para campos de clase, parámetros, retornos ni con valor inicial null.
donde.de: Nur für lokale Variablen in Methoden oder Schleifen mit direktem Startwert; NICHT für Klassenfelder, Parameter, Rückgabetypen oder null-Initialisierung.
donde.en: Use only for local variables inside methods or loops with an initializer; NOT allowed for class fields, parameters, return types, or with a null initializer.
ejemplo: var enemigos = enemigosVistos();  // List<Enemigo>

=== sintaxis.final
tema: 02
firma: final tipo nombre = valor;      static final tipo CONSTANTE = valor;
es: Una variable que no se puede reasignar. Las constantes de clase van en MAYÚSCULAS con static final.
de: Eine Variable, die nicht neu zugewiesen werden kann. Klassenkonstanten: static final, in GROSSBUCHSTABEN.
en: A variable that can't be reassigned. Class constants use static final and UPPER_CASE names.
donde.es: Pon static final en el cuerpo de la clase para constantes globales, y final en variables locales o parámetros que no deban cambiar; nunca reasignes después.
donde.de: static final im Klassenrumpf für Konstanten, final bei lokalen Variablen oder Parametern, die fest bleiben sollen; danach keine Neuzuweisung.
donde.en: Put static final in the class body for constants, and final on local variables or parameters that must not change; never reassign afterward.
ejemplo: static final double DISTANCIA_SEGURA = 150;

=== sintaxis.cast
tema: 02
firma: (tipo) expresion
es: Convierte un valor a otro tipo. De double a int corta los decimales (no redondea).
de: Wandelt einen Wert in einen anderen Typ um. Von double nach int werden Nachkommastellen abgeschnitten.
en: Converts a value to another type. From double to int the decimals are cut off (not rounded).
donde.es: Colócalo justo delante de una expresión numérica dentro de una asignación o argumento cuando necesites convertir de un tipo a otro (p. ej. double a int); usa paréntesis si hay suma.
donde.de: Direkt vor einen numerischen Ausdruck setzen, wenn du bewusst umwandelst (z. B. double nach int); bei Summen den Ausdruck einklammern.
donde.en: Place directly before a numeric expression when intentionally narrowing (e.g. double to int); parenthesize compound expressions first.
ejemplo: int pasos = (int) 7.9;  // 7

=== Integer.MAX_VALUE
tema: 02
firma: static final int MAX_VALUE   // 2147483647   (y MIN_VALUE: -2147483648)
es: El int más grande. Si te pasas, da la vuelta a negativo (desbordamiento). Para más, usa long.
de: Der größte int. Gehst du darüber, springt er ins Negative (Überlauf). Für mehr nimm long.
en: The largest int. Go past it and it wraps around to negative (overflow). For more, use long.
donde.es: Úsalo como valor inicial de búsqueda de mínimo (int mejor = Integer.MAX_VALUE;) antes de un bucle; no le sumes 1 o desbordará a negativo.
donde.de: Als Startwert für Minimum-Suchen (int min = Integer.MAX_VALUE;) vor einer Schleife einsetzen; nicht noch 1 addieren, sonst Überlauf ins Negative.
donde.en: Use as the initial sentinel before a minimum-finding loop (int best = Integer.MAX_VALUE;); avoid adding 1 or it overflows to negative.
ejemplo: int x = Integer.MAX_VALUE + 1;  // -2147483648

# ==================================================================== 03 Operadores y expresiones

=== sintaxis.aritmetica
tema: 03
firma: a + b   a - b   a * b   a / b   a % b
es: Suma, resta, multiplicación, división y resto. Entre dos int, «/» descarta los decimales.
de: Addition, Subtraktion, Multiplikation, Division und Rest. Zwischen zwei int verwirft „/“ die Nachkommastellen.
en: Addition, subtraction, multiplication, division and remainder. Between two ints, “/” drops the decimals.
donde.es: Combínalos dentro de expresiones numéricas en asignaciones, condiciones o argumentos; vigila la división entera (5 / 2 es 2) y no dividas entre 0.
donde.de: In Rechenausdrücken, Zuweisungen oder Argumenten nutzen; bei Ganzzahldivision (5 / 2 ergibt 2) aufpassen und nie durch 0 teilen.
donde.en: Use inside numeric expressions, assignments, or arguments; watch integer division (5 / 2 is 2) and never divide by 0.
ejemplo: 7 / 2  // 3      7 / 2.0  // 3.5      7 % 2  // 1

=== sintaxis.incremento
tema: 03
firma: x++   x--   ++x   --x   x += n   x -= n   x *= n   x /= n
es: Atajos para cambiar una variable: x++ suma 1, x += 5 suma 5.
de: Abkürzungen zum Ändern einer Variable: x++ addiert 1, x += 5 addiert 5.
en: Shortcuts to change a variable: x++ adds 1, x += 5 adds 5.
donde.es: Úsalo como sentencia propia, en el paso de un for o para actualizar contadores; evita meter x++ varias veces en la misma expresión porque confunde.
donde.de: Als eigene Anweisung, im Schritt eines for oder für Zähler nutzen; nicht mehrfach in einem einzigen Ausdruck mischen, da es unlesbar wird.
donde.en: Use as a standalone statement, in a for-loop update, or for counters; avoid embedding x++ multiple times inside one complex expression.
ejemplo: int turnos = 0; turnos++; turnos += 10;  // 11

=== sintaxis.comparacion
tema: 03
firma: a == b   a != b   a < b   a <= b   a > b   a >= b
es: Comparan dos valores y dan un boolean. Para textos y objetos usa equals, no ==.
de: Vergleichen zwei Werte und liefern einen boolean. Für Texte und Objekte nimm equals, nicht ==.
en: Compare two values and give a boolean. For strings and objects use equals, not ==.
donde.es: Ponlos en condiciones de if, while, for o expresiones boolean; usa == solo para primitivos (para String y objetos, usa .equals()).
donde.de: In Bedingungen von if, while, for oder boolean-Ausdrücken einsetzen; == nur für primitive Typen nutzen (bei String und Objekten immer .equals()).
donde.en: Place in if, while, for, or boolean expressions; use == only for primitives (for Strings and objects, use .equals() instead).
ejemplo: boolean cerca = e.distancia() < 100;

=== sintaxis.logicos
tema: 03
firma: a && b   a || b   !a
es: Y, O y NO. && y || no miran la parte derecha si ya saben el resultado (cortocircuito).
de: UND, ODER und NICHT. && und || werten rechts nicht aus, wenn das Ergebnis schon feststeht (Kurzschluss).
en: AND, OR and NOT. && and || skip the right side when the result is already known (short-circuit).
donde.es: Úsalos para combinar expresiones boolean en if o while; pon primero la comprobación más segura (como x != null && ...) gracias al cortocircuito.
donde.de: Zum Verknüpfen von boolean-Bedingungen in if oder while nutzen; sichere Prüfungen (wie x != null && ...) dank Kurzschluss nach vorne setzen.
donde.en: Combine boolean conditions in if or while; place safety guards first (like x != null && ...) to benefit from short-circuit evaluation.
ejemplo: if (listoDerecha() && energia() > 10) atacarDerecha();

=== sintaxis.ternario
tema: 03
firma: condicion ? valorSiTrue : valorSiFalse
es: Un if en forma de expresión: elige entre dos valores.
de: Ein if als Ausdruck: wählt zwischen zwei Werten.
en: An if as an expression: picks one of two values.
donde.es: Úsalo dentro de una asignación, return o argumento para elegir entre dos valores simples; no lo uses como sentencia suelta ni anides varios seguidos.
donde.de: In Zuweisungen, return oder Argumenten für eine kurze Entweder-oder-Wahl nutzen; nicht als alleinstehende Anweisung und nicht tief verschachteln.
donde.en: Use inside an assignment, return, or argument to pick between two values; never as a standalone statement and avoid deep nesting.
ejemplo: double paso = blindaje() < 30 ? -50 : 50;

=== sintaxis.precedencia
tema: 03
firma: ()   !  ++  --   * / %   + -   < > <= >=   == !=   &&   ||   ?:   = +=
es: El orden en que se calculan los operadores, de primero a último. En caso de duda, paréntesis.
de: Die Reihenfolge, in der Operatoren ausgewertet werden, vom ersten bis zum letzten. Im Zweifel Klammern.
en: The order in which operators are evaluated, first to last. When in doubt, use parentheses.
donde.es: Aplícala al escribir expresiones largas dentro de cálculos o condiciones; ante cualquier duda, añade paréntesis () en lugar de fiarte de la memoria.
donde.de: Beim Schreiben längerer Ausdrücke in Rechnungen oder Bedingungen beachten; im Zweifel lieber Klammern () setzen, statt zu raten.
donde.en: Keep it in mind when writing multi-operator expressions; whenever in doubt, add parentheses () rather than relying on memory.
ejemplo: 2 + 3 * 4  // 14      (2 + 3) * 4  // 20
