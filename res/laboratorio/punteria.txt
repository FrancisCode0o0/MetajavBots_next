=== punteria
titulo.es: Pruebas para la puntería
titulo.de: Tests für die Trefferquote
titulo.en: Tests for accuracy
enunciado.es: Estadistica.punteria(int aciertos, int ataques) devuelve la parte de ataques que acertaron, como double entre 0 y 1 (3 de 4 da 0.75); con 0 ataques devuelve 0. Escribe al menos 3 pruebas que cacen a los tres mutantes. Ojo con la división entera.
enunciado.de: Estadistica.punteria(int aciertos, int ataques) gibt den Anteil der Treffer als double zwischen 0 und 1 zurück (3 von 4 ergibt 0.75); bei 0 Angriffen gibt sie 0 zurück. Schreibe mindestens 3 Tests, die die drei Mutanten fangen. Vorsicht bei der Ganzzahldivision.
enunciado.en: Estadistica.punteria(int aciertos, int ataques) returns the share of attacks that hit, as a double between 0 and 1 (3 of 4 gives 0.75); with 0 attacks it returns 0. Write at least 3 tests that catch the three mutants. Watch out for integer division.

    public class Estadistica {
        public static double punteria(int aciertos, int ataques) {
            if (ataques == 0) return 0;
            return (double) aciertos / ataques;
        }
    }

solucion:
    import static metajavbots.junit.Assertions.*;
    import metajavbots.junit.*;

    public class PruebasPunteria {

        @Test
        void tresDeCuatro() {
            assertEquals(0.75, Estadistica.punteria(3, 4), 1e-9);
        }

        @Test
        void sinAtaques() {
            assertEquals(0.0, Estadistica.punteria(0, 0), 1e-9);
        }

        @Test
        void unoDeDos() {
            assertEquals(0.5, Estadistica.punteria(1, 2), 1e-9);
        }
    }
