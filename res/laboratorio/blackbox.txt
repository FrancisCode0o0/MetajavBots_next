Caza a los cuatro mutantes probando negativos, cero, el límite exacto y arrays vacíos.

Summiert die Ladungen bis maximal limite; bei null oder leerem Array kommt 0 zurück; bei limite < 0 oder negativer Ladung wird eine IllegalArgumentException geworfen. Fange alle vier Mutanten mit Negativwerten, Null, exaktem Grenzwert und leerem Array.
enunciado.en: Blackbox strategy: test AnalizadorDeEnergia.consumoSeguro(int[] cargas, int limite) using equivalence classes and boundary values without relying on internals. Sums charges capped at limite; returns 0 for a null or empty array; throws IllegalArgumentException if limite < 0 or any charge is negative. Catch all four mutants by testing negatives, zero, exact boundaries, and empty arrays.
clase:
    public class AnalizadorDeEnergia {
        public static int consumoSeguro(int[] cargas, int limite) {
            if (limite < 0) throw new IllegalArgumentException("límite negativo");
            if (cargas == null || cargas.length == 0) return 0;
            int total = 0;
            for (int c : cargas) {
                if (c < 0) throw new IllegalArgumentException("carga negativa");
                total += c;
                if (total >= limite) return limite;
            }
            return total;
        }
    }

solucion:
    import static metajavbots.junit.Assertions.*;
    import metajavbots.junit.*;

    public class PruebasBlackbox {

        @Test
        void arrayVacioDevuelveCero() {
            assertEquals(0, AnalizadorDeEnergia.consumoSeguro(new int[]{}, 50));
        }

        @Test
        void limiteCeroDevuelveCero() {
            assertEquals(0, AnalizadorDeEnergia.consumoSeguro(new int[]{5, 10}, 0));
        }

        @Test
        void cargaNegativaLanzaExcepcion() {
            assertThrows(IllegalArgumentException.class,
                    () -> AnalizadorDeEnergia.consumoSeguro(new int[]{10, -2}, 50));
        }

        @Test
        void limiteExactoNoRecortaDeMas() {
            assertEquals(10, AnalizadorDeEnergia.consumoSeguro(new int[]{4, 6}, 10));
        }
    }
