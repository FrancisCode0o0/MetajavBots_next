# ERRORES de compilación explicados según el nivel del jugador (noob, junior, senior) y el idioma.
# Un bloque por código de diagnóstico de javac (Diagnostic.getCode(), «compiler.err.…»), más los
# propios del juego («metajavbots.…»). Cada bloque tiene nueve líneas «nivel.idioma = texto».
# Marcadores: {msg} es el mensaje original de javac (ya traducido por javac) y {linea}, la línea.
# Las claves están comprobadas con javac 26 (-XDrawDiagnostics); las que solo existen en versiones
# anteriores lo dicen en un comentario. compiler.err.incompatible.types y compiler.err.class.expected
# ya no existen: javac moderno usa compiler.err.prob.found.req y compiler.err.dot.class.expected.

# ==================================================================== sintaxis: falta o sobra algo

junior.en = Syntax error: a symbol is missing ({msg}). Check the end of line {linea} and of the line before.

noob.en = This "else" has no "if" right before it. Most common: a ";" after the if, "if (x > 0);", or two commands without braces. Use braces: "if (x > 0) { a(); b(); } else { c(); }".
junior.es = else sin if: revisa el «;» tras la condición y las llaves del bloque del if.
