# Tema 13: interfaces.
=== l13_contratos
tema: 13
orden: 1
titulo.es: Contratos, no planos
titulo.de: Verträge statt Baupläne
titulo.en: Contracts, not blueprints
--- pagina
es: Llevas desde el tema 1 usando una interfaz: Enemigo. Le preguntas e.distancia() o e.angulo()
es: y nunca has visto CÓMO se calcula. Una interfaz es un contrato: dice QUÉ métodos hay, no cómo
es: funcionan. La arena tiene su propia clase secreta que lo cumple, y a ti te da igual cuál sea.
de: Du benutzt seit Thema 1 ein Interface: Gegner (Enemigo). Du fragst g.entfernung() oder g.winkel() und
de: hast nie gesehen, WIE das berechnet wird. Ein Interface ist ein Vertrag: Es sagt, WELCHE Methoden es
de: gibt, nicht, wie sie funktionieren. Die Arena hat ihre eigene geheime Klasse, die ihn erfüllt, und
de: welche, ist dir egal.
en: You've been using an interface since topic 1: Enemy (Enemigo). You ask e.distance() or e.angle()
en: and you've never seen HOW it's calculated. An interface is a contract: it says WHICH methods exist,
en: not how they work. The arena has its own secret class that fulfils it, and you don't care which one.
--- pagina
es: Una clase firma el contrato con implements y entonces tiene que escribir todos sus métodos.
es: La diferencia con heredar: una clase solo puede extender a UN padre, pero puede implementar
es: TODAS las interfaces que quiera. Un robot puede ser a la vez Reparable, Volador y Ruidoso.
de: Eine Klasse unterschreibt den Vertrag mit implements und muss dann alle seine Methoden schreiben.
de: Der Unterschied zum Erben: Eine Klasse kann nur EINE Elternklasse erweitern, aber BELIEBIG viele
de: Interfaces implementieren. Ein Roboter kann gleichzeitig reparierbar, fliegend und laut sein.
en: A class signs the contract with implements and then has to write all its methods.
en: The difference from inheritance: a class can only extend ONE parent, but it can implement
en: AS MANY interfaces as it likes. A robot can be Repairable, Flying and Noisy all at once.
codigo:
    interface Punteria {
        double angulo(Metajavbot yo, Enemigo e);
    }
    class Directa implements Punteria {
        @Override
        public double angulo(Metajavbot yo, Enemigo e) {
            return e.angulo();
        }
    }
--- pagina
es: Error típico: olvidar public al implementar. Los métodos de una interfaz son públicos por fuerza,
es: y tu versión no puede ser «menos pública»: sin public, el compilador dice
es: «attempting to assign weaker access privileges». Ahora ya sabes qué significa.
de: Typischer Fehler: beim Implementieren public vergessen. Methoden eines Interfaces sind zwingend öffentlich,
de: und deine Version darf nicht „weniger öffentlich“ sein: Ohne public meldet der Compiler
de: „attempting to assign weaker access privileges“. Jetzt weißt du, was das heißt.
en: Typical mistake: forgetting public when implementing. Interface methods are public by force,
en: and your version can't be "less public": without public, the compiler says
en: "attempting to assign weaker access privileges". Now you know what it means.

en: Define your own interface (Punteria, for example), implement it and aim with it for a round.

=== l13_estrategias
tema: 13
orden: 2
titulo.es: Cambiar la puntería en marcha
titulo.de: Das Zielen im Lauf wechseln
titulo.en: Swapping your aim on the fly
--- pagina
es: Con una interfaz, la forma de apuntar se vuelve una pieza intercambiable: el patrón Estrategia.
es: La puntería directa va bien contra robots lentos; contra los rápidos, mejor apuntar adonde ESTARÁN.
es: El robot guarda una Punteria y la cambia según lo que vea, sin tocar nada más del código.
de: Mit einem Interface wird das Zielen zum austauschbaren Bauteil: das Strategie-Muster.
de: Direktes Zielen klappt gegen langsame Roboter; gegen schnelle zielst du besser dorthin, wo sie SEIN WERDEN.
de: Der Roboter merkt sich eine Punteria und wechselt sie je nach Lage, ohne sonst etwas am Code zu ändern.
en: With an interface, the way you aim becomes a swappable part: the Strategy pattern.
en: Direct aim works against slow robots; against fast ones, better aim where they WILL BE.
en: The robot keeps a Punteria and swaps it depending on what it sees, without touching the rest of the code.
codigo:
    class Adelantada implements Punteria {
        @Override
        public double angulo(Metajavbot yo, Enemigo e) {
            double turnos = e.distancia() / 14;     // lo que tarda en llegar, más o menos
            double r = Math.toRadians(e.rumbo());
            double fx = e.x() + Math.cos(r) * e.velocidad() * turnos;
            double fy = e.y() + Math.sin(r) * e.velocidad() * turnos;
            return yo.anguloHacia(fx, fy);
        }
    }
    @Override
    public void alVerEnemigo(Enemigo e) {
        Punteria p = Math.abs(e.velocidad()) > 3 ? new Adelantada() : new Directa();
        apuntarHacia(p.angulo(this, e));
        atacar();
    }
--- pagina
es: Desde Java 8 una interfaz puede traer métodos default: con cuerpo, listos para usar, que cada clase
es: puede sobrescribir si quiere. Sirven para añadir métodos a una interfaz sin romper las clases
es: que ya la implementaban. También admite métodos static (Java 8) y private (Java 9) de ayuda.
de: Seit Java 8 kann ein Interface default-Methoden mitbringen: mit Rumpf, sofort benutzbar, und jede Klasse
de: darf sie überschreiben. So ergänzt man ein Interface um Methoden, ohne die Klassen zu zerbrechen,
de: die es schon implementieren. Dazu kommen static-Methoden (Java 8) und private Hilfsmethoden (Java 9).
en: Since Java 8 an interface can come with default methods: with a body, ready to use, which each class
en: may override if it wants. They let you add methods to an interface without breaking the classes
en: that already implemented it. Interfaces also allow static (Java 8) and private (Java 9) helper methods.

=== l13_interfaces_de_java
tema: 13
orden: 3
titulo.es: Las interfaces que Java ya trae
titulo.de: Die Interfaces, die Java mitbringt
titulo.en: The interfaces Java ships with
--- pagina
es: Java está lleno de interfaces que puedes firmar. Comparable<T> dice «sé compararme con otro»: implementa
es: compareTo (negativo si voy antes, 0 si empatamos, positivo si voy después) y tus objetos
es: se podrán ordenar con Collections.sort o List.sort. Iterable<T> deja recorrer tu clase con for-each.
de: Java steckt voller Interfaces, die du unterschreiben kannst. Comparable<T> heißt „ich kann mich vergleichen“:
de: Implementiere compareTo (negativ, wenn ich zuerst komme, 0 bei Gleichstand, positiv, wenn danach),
de: und deine Objekte lassen sich mit Collections.sort oder List.sort sortieren. Iterable<T> erlaubt for-each.
en: Java is full of interfaces you can sign. Comparable<T> says "I know how to compare myself": implement
en: compareTo (negative if I come first, 0 for a tie, positive if I come after) and your objects
en: can be sorted with Collections.sort or List.sort. Iterable<T> lets you walk your class with for-each.
codigo:
    class Blanco implements Comparable<Blanco> {
        final double distancia;
        Blanco(double distancia) {
            this.distancia = distancia;
        }
        @Override
        public int compareTo(Blanco otro) {
            return Double.compare(distancia, otro.distancia);   // el más cercano, primero
        }
    }
--- pagina
es: Un fallo sutil: implementar compareTo como return (int) (distancia - otro.distancia).
es: Con decimales, 0.4 se convierte en 0 y dos blancos distintos parecen empatados; con enteros grandes
es: la resta puede desbordarse. Double.compare e Integer.compare existen justo para eso.
de: Ein subtiler Fehler: compareTo als return (int) (distancia - otro.distancia) zu schreiben.
de: Bei Kommazahlen wird 0.4 zu 0, und zwei verschiedene Ziele wirken gleich; bei großen ganzen Zahlen
de: kann die Subtraktion überlaufen. Genau dafür gibt es Double.compare und Integer.compare.
en: A subtle bug: implementing compareTo as return (int) (distancia - otro.distancia).
en: With decimals, 0.4 becomes 0 and two different targets look tied; with big integers
en: the subtraction can overflow. Double.compare and Integer.compare exist exactly for this.
