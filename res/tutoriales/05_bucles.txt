# Tema 05: bucles (while, do-while y for).
=== l05_while
tema: 05
orden: 1
titulo.es: Otra vez, otra vez, otra vez
titulo.de: Nochmal, nochmal, nochmal
titulo.en: Again, again, again
--- pagina
es: Sorpresa: ya usas un bucle sin saberlo. La pelea llama a cadaTurno una y otra vez, 30 veces por segundo:
es: ese es el bucle del juego, y lo lleva la arena. Los bucles que escribas tú son para repetir algo
es: DENTRO de un turno: contar, buscar, calcular. Y tienen que terminar rápido, porque mientras tu bucle
es: da vueltas, el turno no acaba y el robot se queda congelado pensando.
de: Überraschung: Du benutzt schon eine Schleife, ohne es zu wissen. Der Kampf ruft jedenZug immer wieder auf,
de: 30-mal pro Sekunde: Das ist die Spielschleife, und um die kümmert sich die Arena. Deine eigenen Schleifen
de: wiederholen etwas INNERHALB eines Zuges: zählen, suchen, rechnen. Und sie müssen schnell fertig sein,
de: denn solange deine Schleife kreist, endet der Zug nicht, und der Roboter erstarrt beim Nachdenken.
en: Surprise: you're already using a loop without knowing it. The fight calls onTick over and over,
en: 30 times a second: that's the game loop, and the arena runs it. The loops you write repeat something
en: WITHIN a turn: counting, searching, calculating. And they must finish fast, because while your loop
en: spins, the turn doesn't end and the robot freezes, lost in thought.
--- pagina
es: while (condición) { ... } repite mientras la condición sea verdad. Dentro tiene que cambiar algo
es: que acabe volviéndola falsa; si no, el bucle es infinito. La arena lo corta para que no se cuelgue
es: el juego, pero tu robot pierde el turno y el locutor no te lo perdonará.
es: El despiste típico: olvidar el i++ o la línea que hace avanzar la cuenta.
de: while (bedingung) { ... } wiederholt, solange die Bedingung wahr ist. Darin muss sich etwas ändern,
de: das sie irgendwann falsch macht, sonst läuft die Schleife ewig. Die Arena bricht sie ab, damit das Spiel
de: nicht hängt, aber dein Roboter verliert den Zug, und der Sprecher lässt dich das spüren.
de: Der typische Patzer: das i++ vergessen oder die Zeile, die das Zählen voranbringt.
en: while (condition) { ... } repeats as long as the condition is true. Something inside must change
en: so that it eventually becomes false; otherwise the loop is infinite. The arena cuts it off so the game
en: doesn't hang, but your robot loses its turn and the announcer will never let you forget it.
en: The typical slip: forgetting the i++ or the line that moves the count along.
codigo:
    // ¿Cuántos pasos de 50 caben hasta la pared derecha?
    double hueco = anchoArena() - x();
    int pasos = 0;
    while (hueco >= 50) {
        hueco -= 50;
        pasos++;
    }
    escribir("Caben " + pasos + " pasos");

=== l05_for
tema: 05
orden: 2
titulo.es: For: el bucle que cuenta
titulo.de: For: die Zählschleife
titulo.en: For: the counting loop
--- pagina
es: Cuando sabes cuántas vueltas quieres, for lo junta todo en una línea: desde dónde empiezas, hasta cuándo
es: sigues y cómo avanzas. for (int i = 0; i < 3; i++) da tres vueltas: con i valiendo 0, 1 y 2.
es: Los programadores cuentan desde 0 (lo verás en los arrays), así que acostúmbrate pronto.
de: Weißt du, wie viele Runden du willst, packt for alles in eine Zeile: wo du anfängst, wie lange du weitermachst
de: und wie du weiterzählst. for (int i = 0; i < 3; i++) läuft dreimal: mit i gleich 0, 1 und 2.
de: Programmierer zählen ab 0 (das siehst du bei Arrays), also gewöhn dich früh daran.
en: When you know how many laps you want, for puts it all on one line: where you start, how long you keep going
en: and how you step. for (int i = 0; i < 3; i++) goes round three times: with i being 0, 1 and 2.
en: Programmers count from 0 (you'll see why with arrays), so get used to it early.
codigo:
    @Override
    public void alEmpezar() {
        for (int i = 3; i >= 1; i--) {
            escribir(i + "...");
        }
        decir("¡Ya!");
    }
--- pagina
es: El error de «uno de más o uno de menos» es tan común que tiene nombre (off-by-one).
es: i < 3 da 3 vueltas; i <= 3 da 4. Antes de dar por bueno un bucle, prueba de cabeza la primera
es: y la última vuelta: ¿cuánto vale i? ¿Debería entrar? Diez segundos de esto ahorran diez minutos de búsqueda.
de: Der „eins zu viel oder eins zu wenig“-Fehler ist so häufig, dass er einen Namen hat (Off-by-one).
de: i < 3 läuft dreimal; i <= 3 viermal. Bevor du einer Schleife traust, spiel im Kopf die erste und die letzte
de: Runde durch: Welchen Wert hat i? Sollte es hinein? Zehn Sekunden dafür sparen zehn Minuten Suche.
en: The "one too many or one too few" bug is so common it has a name (off-by-one).
en: i < 3 goes round 3 times; i <= 3 goes 4 times. Before trusting a loop, run the first and last lap
en: in your head: what's i? Should it get in? Ten seconds of this saves ten minutes of hunting.
--- pagina
es: Un for también sirve para probar opciones y quedarte con la mejor. Aquí el robot prueba ocho direcciones
es: y elige la que tiene más espacio libre hasta la pared, para no quedarse arrinconado.
de: Mit for kannst du auch Möglichkeiten ausprobieren und die beste behalten. Hier testet der Roboter
de: acht Richtungen und nimmt die mit dem meisten Platz bis zur Wand, damit er nicht in die Ecke gerät.
en: A for loop can also try options and keep the best one. Here the robot tests eight directions
en: and picks the one with the most room before the wall, so it doesn't get cornered.
codigo:
    double mejorAngulo = 0, mejorHueco = -1;
    for (int i = 0; i < 8; i++) {
        double a = Math.toRadians(i * 45);
        double px = x() + Math.cos(a) * 150, py = y() + Math.sin(a) * 150;
        double hueco = Math.min(Math.min(px, anchoArena() - px),
                                Math.min(py, altoArena() - py));
        if (hueco > mejorHueco) {
            mejorHueco = hueco;
            mejorAngulo = i * 45;
        }
    }
    girarHacia(mejorAngulo);

=== l05_do_while_break
tema: 05
orden: 3
titulo.es: Al menos una vez, y salidas de emergencia
titulo.de: Mindestens einmal, und Notausgänge
titulo.en: At least once, and emergency exits
--- pagina
es: do { ... } while (condición); hace la vuelta PRIMERO y pregunta después, así que siempre entra
es: al menos una vez. Viene bien cuando la primera vuelta es obligatoria, como contar las cifras
es: de un número: hasta el 0 tiene una. No olvides el ; del final, que aquí sí va.
de: do { ... } while (bedingung); dreht ZUERST eine Runde und fragt danach, läuft also mindestens einmal.
de: Praktisch, wenn die erste Runde Pflicht ist, etwa beim Zählen der Ziffern einer Zahl: Selbst die 0 hat eine.
de: Vergiss das ; am Ende nicht, hier gehört es hin.
en: do { ... } while (condition); does the lap FIRST and asks afterwards, so it always runs at least once.
en: Handy when the first lap is mandatory, like counting the digits of a number: even 0 has one.
en: Don't forget the ; at the end; here it belongs.
--- pagina
es: break sale del bucle en el acto; continue se salta el resto de la vuelta y pasa a la siguiente.
es: Úsalos cuando ya sabes la respuesta: si buscas el primer número primo, no hace falta seguir mirando
es: después de encontrarlo. Bien usados ahorran trabajo; abusar de ellos hace el bucle difícil de seguir.
de: break verlässt die Schleife sofort; continue überspringt den Rest der Runde und macht mit der nächsten weiter.
de: Nimm sie, wenn du die Antwort schon kennst: Suchst du die erste Primzahl, musst du danach nicht weitersuchen.
de: Gut eingesetzt sparen sie Arbeit; zu viele davon machen die Schleife schwer zu verfolgen.
en: break leaves the loop on the spot; continue skips the rest of the lap and moves on to the next.
en: Use them when you already know the answer: if you're looking for the first prime, no need to keep
en: looking once you've found it. Used well they save work; overused, they make loops hard to follow.
codigo:
    for (int n = 2; n < 100; n++) {
        if (n % 7 != 0) {
            continue;                  // no es múltiplo de 7: siguiente
        }
        escribir("El primer múltiplo de 7 es " + n);
        break;                         // ya está, fuera
    }
--- pagina
es: Un bucle dentro de otro da una vuelta entera por cada vuelta del de fuera: perfecto para dibujar
es: rectángulos con letras, filas por columnas. Si el de fuera da 5 vueltas y el de dentro 10, son 50 en total.
es: Con números grandes eso crece deprisa, y el robot tiene poco tiempo por turno: piensa antes de anidar.
de: Eine Schleife in einer Schleife dreht eine volle Runde pro Runde der äußeren: ideal für Rechtecke aus
de: Buchstaben, Zeilen mal Spalten. 5 Runden außen und 10 innen sind 50 insgesamt.
de: Bei großen Zahlen wächst das schnell, und der Roboter hat pro Zug wenig Zeit: Erst denken, dann verschachteln.
en: A loop inside another does a full lap for every lap of the outer one: perfect for drawing rectangles
en: of letters, rows by columns. 5 laps outside and 10 inside make 50 in total.
en: With big numbers that grows fast, and the robot has little time per turn: think before you nest.
