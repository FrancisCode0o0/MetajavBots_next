=== especial_martillo
tema: 03
dificultad: 1
java: 8
tipo: metodo
titulo.es: Martillo Titán: ¿a qué distancia está?
titulo.de: Titanhammer: Wie weit ist er weg?
titulo.en: Titan Hammer: how far away is it?
enunciado.es: Para cargar con el martillo hay que saber cuánto correr. El enemigo está dx más a la derecha y dy más arriba que tú: devuelve la distancia en línea recta (Pitágoras: raíz cuadrada de dx² + dy²).
enunciado.de: Um mit dem Hammer anzustürmen, musst du die Laufstrecke kennen. Der Gegner ist dx weiter rechts und dy weiter oben als du: Gib den direkten Abstand zurück (Pythagoras: Wurzel aus dx² + dy²).
enunciado.en: To charge with the hammer you need to know how far to run. The enemy is dx right and dy up from you: return the straight-line distance (Pythagoras: square root of dx² + dy²).
pista.es: Math.sqrt(x) calcula la raíz cuadrada; dx * dx es dx al cuadrado.
pista.de: Math.sqrt(x) berechnet die Quadratwurzel; dx * dx ist dx zum Quadrat.
pista.en: Math.sqrt(x) computes the square root; dx * dx is dx squared.
firma: static double distancia(double dx, double dy)
plantilla:
    return 0;
solucion:
    return Math.sqrt(dx * dx + dy * dy);
casos:
    distancia(3, 4) => 5.0
    distancia(6, -8) => 10.0
    distancia(-5, 12) => 13.0
    distancia(0, 0) => 0.0
    distancia(0, -7) => 7.0

=== especial_arpon_giro
tema: 04
dificultad: 3
java: 8
tipo: metodo
titulo.es: Arpón Trueno: giro por el camino corto
titulo.de: Donnerharpune: kürzester Drehweg
titulo.en: Thunder Harpoon: shortest turn angle
enunciado.es: Tu mira apunta a mira grados y el objetivo está en objetivo grados. Devuelve cuántos grados debes girar en el rango (-180, 180] para llegar por el camino más corto.
enunciado.de: Dein Visier zeigt auf mira Grad und das Ziel liegt bei objetivo Grad. Gib die kleinste Drehung in (-180, 180] zurück, um direkt dorthin zu drehen.
enunciado.en: Your sight points at mira degrees and the target is at objetivo degrees. Return the shortest turn in (-180, 180] to rotate straight onto target.
pista.es: Toma d = (objetivo - mira) % 360; si d > 180 resta 360, si d <= -180 suma 360.
pista.de: Nimm d = (objetivo - mira) % 360; wenn d > 180 ziehe 360 ab, wenn d <= -180 addiere 360.
pista.en: Compute d = (objetivo - mira) % 360; if d > 180 subtract 360, if d <= -180 add 360.
firma: static int giroCorto(int mira, int objetivo)
plantilla:
    return 0;
solucion:
    int d = (objetivo - mira) % 360;
    if (d > 180) d -= 360;
    if (d <= -180) d += 360;
    return d;
casos:
    giroCorto(10, 50) => 40
    giroCorto(350, 10) => 20
    giroCorto(10, 350) => -20
    giroCorto(0, 180) => 180
    giroCorto(170, -170) => 20

=== especial_arpon_cadena
tema: 07
dificultad: 3
java: 8
tipo: metodo
titulo.es: Arpón Trueno: salto eléctrico
titulo.de: Donnerharpune: Kettenschlag
titulo.en: Thunder Harpoon: chain lightning
enunciado.es: El arpón puede electrocutar a todos los robots cercanos. Dado el array d de distancias y un límite max, devuelve cuántos objetivos están a distancia menor o igual que max.
enunciado.de: Die Harpune trifft alle nahen Ziele per Blitz. Gib für das Array d mit Abständen und die Grenze max zurück, wie viele Ziele höchstens max entfernt sind.
enunciado.en: The harpoon arcs electricity to nearby targets. Given distance array d and limit max, return how many targets are within distance <= max.
pista.es: Recorre d con un for-each y suma 1 a un contador cada vez que x <= max.
pista.de: Durchlaufe d mit einer for-each-Schleife und zähle jeden Wert mit x <= max.
pista.en: Iterate through d with a for-each loop and increment a counter whenever x <= max.
firma: static int enCadena(int[] d, int max)
plantilla:
    return 0;
solucion:
    int c = 0;
    for (int x : d) if (x <= max) c++;
    return c;
casos:
    enCadena(new int[]{80, 150, 110, 200}, 120) => 2
    enCadena(new int[]{50, 60}, 60) => 2
    enCadena(new int[]{200, 300}, 100) => 0
    enCadena(new int[]{}, 100) => 0
